# Fob OpenMoji subset

Artwork by **OpenMoji — the open-source emoji and icon project**, including its individual contributors.

- Source: https://github.com/hfg-gmuend/openmoji/tree/17.0.0
- Project: https://openmoji.org/
- License: Creative Commons Attribution-ShareAlike 4.0 International, https://creativecommons.org/licenses/by-sa/4.0/
- License text: `/licenses/openmoji.txt`
- Fob includes 448 original, unmodified color SVGs. The Unicode values, pinned source URLs and SHA-256 hashes are recorded in `sources.json`.

Use `node scripts/sync-openmoji.mjs` to reproduce the reviewed subset. Category names, translations and search aliases belong to Fob's catalog; the artwork itself is unchanged.
