# 煤球 AI 对话

煤球是 Fob 唯一的独立聊天入口。点击精灵，在它身旁展开轻量气泡，与同一个知识伙伴连续对话。文档内的生成块、选区改写与 AI 接入设置仍各自保留。已撤回的独立助手窗口和文档顶栏 AI 按钮不再使用。

## 交互与视觉

视觉依据是用户明确选定的 imagegen 展示第 1 张 **Whisper Bubbles**，不是第 2 张或历史助手窗口。使用现有煤球毛发与眼睛，透明气泡组合没有外框、标题栏或侧栏；不会改变文档宽度。桌面列宽 304px，正文 14px，独立输入胶囊约 40px 高，对话增长时仅消息区滚动。白色回答、浅灰提问、指向煤球的尾部，以及原文引用构成主要层次。

- 点击或 Enter/Space 开合聊天；关闭不取消正在进行的回答，重开重新验证访问权限。
- 输入支持 Enter 发送、Shift+Enter 换行与中文输入法。只有服务端接受请求后才清空草稿。停止会保留已有内容。
- 默认使用当前文档；没有活动文档时使用整个知识库。资料范围可从顶部小胶囊切换；生成期间不切换范围。
- 次级菜单提供新对话、最近对话、AI 接入设置与原精灵互动。最近对话可搜索并经确认删除；回答可复制或重新回答。
- 右键、ContextMenu 或 Shift+F10 仍可打开原精灵互动，与聊天互斥。全局召唤事件打开聊天。
- 引用只从服务端披露的来源中解析，通过现有文档导航所有者打开对应页面和块。普通闲聊不会列出无关的资料清单。
- 精灵拖动时气泡跟随；横向空间不足时移到上方/下方。位置遵循 `visualViewport`，避让窄屏、视口平移与模拟软键盘；恢复视口后保留用户原位置。
- 使用现有共享控件、图标、颜色、菜单、Tooltip 和错误材质，支持深色与减少动态效果。无法连接模型、未登录、本机库和权限变化均呈现真实状态。
- 回答尾部使用与气泡同色的短尾，沿边缘接合，不单独叠加尾部阴影；气泡和输入描边从 `--muted` 混合面板色得到，输入焦点仅变为 `--muted`。单行文本域与发送按钮等高并垂直居中，多行自动增高，发送按钮保持底部对齐。
- 互动栏保留动作、表情、喂食三个入口。抚摸、跳跃、炸毛和睡觉集中在动作菜单，睡觉不再重复出现在表情菜单。保持原有动作、忙碌门禁、键盘和触摸操作。
- 按角色实际缩放后的大小调整反馈：爱心约 11px、糖果约 14px、睡眠标记约 11–16px。爱心和糖果复用统一图标目录的官方实心图形，动画仍由角色控制器负责。

## 组成与数据流

```text
Workbench 身份 / 选中知识库 ── CompanionContextBridge ─┐
活动且可见的 EditorSurface ── 文档 publication ──────┤
                                                  ▼
                                        CompanionContextStore
                                                  ▼
煤球点击 ── CompanionWidget ── CompanionChat + ConversationSession
                                                  ▼
                          authenticated assistantApi / NDJSON
                                                  ▼
                 user + knowledgeBase ACL → Agent → 模型服务商 / 只读工具
                                                  ▼
                       私有持久会话 / 授权来源 / 流式回答
```

`GlobalCompanion` 位于工作台业务 Provider 之外。`CompanionContextStore` 通过独立的工作区和文档发布租约接收最小投影，不重新创建认证 Provider，不从 URL 或 DOM 猜测上下文。只有用户和知识库匹配的、活动且可见的当前文档可以成为资料范围；隐藏页签、历史版本预览与旧租约清理不会覆盖新上下文。

`CompanionConversationSession` 是与 React Provider 无关的状态机，`useCompanionConversation` 用 `useSyncExternalStore` 接入。它负责配置加载、历史、流式事件、取消、网络恢复和请求去重；气泡组件只负责呈现、输入与用户操作。切换用户或知识库同步隐藏旧私有字段，随后递增 epoch、中断旧请求并隔离迟到事件。仅文档变化时，文档模式停止旧生成，知识库模式可以继续。

浏览器只保存最多 10 个作用域的 UUID 会话指针，不保存问题、回答、来源或凭据。恢复、重开和焦点返回均从后端重新验证；运行中的会话轮询终态，完成后的已选会话也定期复查。后端撤权/不可访问后立即清除相关前端答案。真实数据保留和 Agent 工具/预算边界见 [知识助手架构](knowledge-assistant-agent.md)。

`AssistantAsk.pageId` 在整个知识库模式允许空值；当前文档模式仍要求有效页面 ID。空值不会转成虚构文档。后端对整个知识库先授权，再由现有检索、阅读与反向链接工具逐项验证页面；会话仍按真实用户和知识库隔离。煤球人格指令保持简短自然，知识性回答以授权资料为依据。

## 边界

聊天使用已配置的快速默认模型，模型、服务商和凭据在统一 AI 接入设置管理。模型密钥只在服务端解析；客户端使用现有认证 API。本次气泡没有额外暴露模型清单、推理内容或工具调试过程。

煤球可以阅读和检索获准访问的知识，回答和引用资料；不会以聊天消息直接修改文档。文档生成、修改建议及采纳仍通过现有生成块/审阅流程处理。本机知识库暂不支持 AI 对话，界面明确提示切换到服务端库。
