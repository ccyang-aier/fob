# 文档协作、分享与洞察

当前设计以 Fob 知识库、页面 ACL、Yjs 文档及自有身份体系为边界。视觉参考来自 Outline 在线成员、分享和权限弹窗；历史记录和统计沿用同一材质并补足信息层级。设计与实现不依赖 Outline 服务、数据库或登录状态。

## 在线成员

编辑器使用真实 Hocuspocus awareness，按账户合并多窗口头像，显示在线状态、当地时间及浏览/编辑状态。资料卡里的身份、姓名和头像由服务器已验证身份覆盖，客户端不能冒充另一账户或 agent，也不能覆盖其他连接拥有的 awareness clientId。只读用户不能报告正在编辑。

页面 ACL 变更提交后同步复核现有连接；Redis 权限事件和每两秒复核覆盖分组、成员及会话变动。每次文档同步还会重新验证身份和权限，失去编辑权后拒绝写入，失去查看权后断开连接。

## 授权和邀请

- 新资源授权为查看、编辑、管理三级，历史 comment 读取兼容为查看；成员阅读后可以评论，访客与公开只读链接没有评论能力。工作空间角色和资源权限分开，合成及可见数据规则统一见[知识权限设计](architecture/knowledge-permissions.md)；降低一个直接授权不会覆盖更高的继承授权。
- 管理授权先要求实际页面阅读权，再检查文档管理、文件夹管理或知识库管理能力，全局管理员不绕过私有正文。变更在知识库权限锁下提交，完整刷新目标子树的权限物化后响应，保留最后一个直接管理授权。断开继承时为操作者保留直接管理授权。
- 新增跨知识库账户的邀请还要求知识库 owner/admin。邀请绑定已验证邮箱，七天有效，一次性接受；重发、撤销、过期或邮箱不符均不可接受。
- 接受邀请只增加 guest 成员及目标页面授权。guest 不获得知识库默认权限，只通过用户或分组的明确授权访问页面。已有更高授权不会被邀请降级。
- 所有角色只能下载当前可访问页面实际引用的附件，不能以知识库成员身份或已知哈希绕过私有文档。上传需要知识库管理身份或实际可编辑的位置；全库资产撤销限知识库管理者。
- 邀请生成可复制链接，由用户自行发送，界面不声称已发送邮件。

## 发布至网络

非访客且具有实际文档管理级授权的成员可以启用、停用、重新生成公开只读链接，并立即调整有效期；管理文档成员的能力不自动授予公开发布能力。重新生成会撤销旧凭证；停用会撤销该页面所有活动链接和对应 ACL 授权。查询快照时，页面、未撤销及有效期整体合取，不选出另一页面或已撤销的链接。

数据库保存令牌摘要及 AES-256-GCM 密文，密钥由 Fob 认证密钥派生；同一活动链接可重新打开并复制。认证密钥轮换后旧密文无法恢复，管理者仍可停用或重新生成链接。公开访问验证摘要、有效期、撤销状态和页面 ACL，不依赖密文解密。

Web `/share` 把凭证放在 URL fragment，以无 Cookie 的 POST 请求读取文档。公开响应无缓存、不包含成员目录或 ACL。附件代理每次重验凭证、知识库和当前正文引用，只返回已确认且未撤销的对象；不提供可绕过后续撤权的 S3 公开下载链接。公开页面在聚焦及每三十秒重验；已加载内容不能从查看者设备追溯删除。

## 页面动态

文档更多菜单的“动态”打开右侧“页面动态”栏，仅提供浏览记录、版本两个分段页签。默认浏览记录；支持方向键、Home/End 切换，真实头像、姓名与时间，以及加载、失败重试、空态。`HistoryPanel` 负责侧栏，`ActivityList` 使用固定头像列、弹性姓名列与右对齐时间列；图片头像与首字母头像同为 24px，并以 20px 文本行盒垂直居中。`VersionsPanel` 与 `VersionList` 仅展示版本记录及日期分组。

浏览记录按账户去重，同一账户再访问时更新最近时间；按最近时间、用户 ID 倒序保留二十位。编辑记录入口已经移除；内部已提交编辑事件仍按原规则最多保留二十条，幂等事件不重复记录。段落编辑归属的派生 Yjs 更新复用原正文保存，避免覆盖经过验证的编辑身份。

`document_visit`、独立的 `document_edit`、`doc_checkpoint` 通过数据库触发器分别限制为每个知识库、每篇文档 **20 位浏览用户、20 次编辑、15 个版本**。写入事务以表、知识库和页面为键串行清理，排序包含稳定 ID，超额行直接删除。触发器使用调用者权限，保留强制 RLS；删除页面时相关记录级联删除。当前正文 `doc_state` 与任务 outbox 的投递/去重账本不属于动态记录清理范围。

### 版本

沿用 GC 开启的 Yjs 完整快照：有变更且距上次版本满十分钟时、最后连接卸载时、手动命名时记录版本。命名长度最多 200 字符；相同正文和标题复用最新快照。比较完整状态（包括删除集合），避免漏记仅删除操作。

版本记录标题、时间及真实编辑者。列表按时间及 ID 倒序，保留最近十五个快照，按今天、昨天及日期分组。点击记录后，主文档区域直接切换为该版本的标题和完整正文；选择“当前版本”、正文的返回入口或关闭动态栏后切回当前文档。页面不再提供高亮、比较、保存版本或侧栏内的小预览。

`useDocumentVersion` 隔离版本查询、选择和作用域；`VersionDocument` 使用共享 schema 与相同块渲染器创建独立只读编辑器。当前协同 Y.Doc 和编辑器继续存活，历史浏览不替换或提交当前正文，返回后恢复原编辑权限及实时内容。版本加载失败明确显示错误和重试，跨页面切换不沿用旧快照。历史附件仅在对应快照仍保留且当前页面 ACL 可查看时允许访问；快照删除和撤权后不再通过该快照授权附件下载。原恢复/比较接口保留兼容，不再由此界面调用。

## 文档互动

正文编辑器顶栏左侧依次为收藏、点赞、送咖啡、评论。标题下方不再重复显示评论入口；评论按钮与更多菜单继续控制同一真实评论侧栏。权限说明通过标题下方元信息右侧的提醒图标展示，不在正文前插入横幅。常规只读使用警示色，同步鉴权失败使用错误色；鼠标悬停或键盘聚焦时以共享 Tooltip 显示完整原因和恢复说明。图标有完整可访问名称，窄屏允许元信息换行并保留图标点击区。

点赞按知识库、文档、账户唯一保存，可取消；数量与当前账户的状态来自真实接口。点赞确认后播放回弹和粒子亮点，送出咖啡确认后播放举杯、蒸汽、飞杯和粒子，评论入口播放气泡弹跳。动画只负责反馈，不伪造计数或余额；失败显示共享 Toast。所有动效遵守减少动态效果偏好，切号/关闭后的迟到结果不回写旧界面。

送咖啡弹窗显示真实创建者、当前账户余额、快捷数量与自定义数量（1–1000 杯）；点击“送出 N 杯咖啡”后才提交。不允许送给自己、无页面查看权者赠送、余额不足或账户不匹配。服务器从页面真实创建者确定收赠人；同一发送者的请求 ID 唯一，重试不重复扣减，相同请求 ID 改数量或改目标会拒绝。

`coffee_ledger` 保留每日签到入账；新增只增不改的 `coffee_transfer` 记录赠送。余额为签到奖励加收到数量减送出数量，账本接口统一按时间和 ID 分页并保留完整时间精度。跨知识库赠送使用同一发送者锁，数据库触发器再次校验来源页面、真实收赠人和余额；账户 RLS 只允许账户读取自己的收支、发送者在已验证身份和知识库作用域下插入，普通角色不能改写或删除转账。转账不随原文档/知识库删除而消失，避免余额被历史内容删除改变。个人统计与共鸣勋章同步计入文档点赞，收获咖啡仅汇总真实赠送。

## 辅助侧栏

评论和页面动态右侧栏共用 `DocumentSidebar` 与系统分隔手柄。沿左侧边界向左拖动扩大、向右拖动缩小，也支持方向键微调；默认宽度分别为 364px、400px，范围 280–640px。宽度按当前文档视图作用域保存，关闭后重开继续使用；窄屏仍受容器和视口约束。反馈沿用全局 1px 分隔指示线和拖拽光标。

## 评论内容与锚点

普通评论、回复、编辑和选中文本的快捷评论共用同一个输入器，接入 Fob 的 448 个 OpenMoji 表情及统一搜索、分类、键盘操作。表情卡优先向触发器左侧展开，与底部操作行对齐，空间不足时翻转或回退至上下方，并避让视口。选择表情后插入原光标处，可单独发送表情；仍保存标准 Unicode Markdown，失败保留草稿。阅读时将精选集内的表情显示为本地 OpenMoji，未知 Unicode 保留原样，代码内容保持字面文本。评论入口和回复统一使用 `ChatCircleDots`。

有评论的正文使用专属浅蓝色背景与细底线，激活时加深，深色模式使用对应低亮度蓝色；不依赖中性的主题强调色。已解决、孤立和发送中状态保留原有语义。评论计数仍跟随引用范围末尾，以所在文字的 `em` 定位高度，使大标题的角标高于字面而不压住相邻文字；计数不进入导出正文。

交互与回归证据见[评论与文字工具任务](../.spec/tasks/comment-text-tools.md)。

## 统计口径

统计读取持久化正文与元数据，计算 Unicode 字符、分词、非空段落和按每分钟二百词估算的阅读时间。创建者、真实编辑事件及版本作者构成贡献者；版本数来自实际快照。

成员阅读使用 `document_visit`，同账户、同页面三十分钟内连续访问不增加次数，但刷新最近浏览时间。阅读次数、独立成员数及成员阅读列表均基于保留的最近二十位成员记录，不代表完整历史累计；淘汰的行包含其阅读和学习计数。公开匿名阅读不计入这些数值，界面明确标为“成员阅读”。

## 接口与数据升级

会话接口前缀为 `/api/knowledge/:knowledgeBaseId/pages/:pageId/collaboration`，提供分享快照、目录、权限、继承、发布、邀请、访问记录及统计；`GET /activity` 经实时页面查看权限验证后返回有界的浏览、编辑记录，不缓存。版本接口沿用 `/checkpoints`，包含比较和恢复，列表最多十五条。接受邀请使用 `/api/document-invitations/accept`；公开读取使用 `/api/public/documents` 及 `/assets/:hash`。

新增 `resources.document_visit`、`resources.document_invitation`，并为 share_link 增加 encrypted_token、doc_checkpoint 增加 title。全部业务表启用并强制知识库 RLS。新数据库使用当前 schema；已有数据库执行增量升级，不重置数据：

```powershell
bun --env-file=.env.fob.local backend/server/scripts/upgrade-document-collaboration.ts
bun --env-file=.env.fob.local backend/server/scripts/upgrade-page-activity.ts
bun --env-file=.env.fob.local backend/server/scripts/upgrade-document-interactions.ts
bun --env-file=.env.fob.local backend/server/scripts/database.ts check
```

动态升级脚本在管理员事务中添加编辑记录表、索引和强制 RLS，安装保留规则，从已有真实编辑事件回填每篇最新二十条，并清理现存超额记录；可重复执行，不重置数据库。新数据库初始化同样安装保留规则。验证见[页面动态任务](../.spec/tasks/page-activity.md)。

本地离线知识库不伪造多人协作、公开发布、页面动态或服务器统计；分享入口说明需要团队知识库。运行依赖使用 Fob 的 PostgreSQL、Redis、S3、认证配置及后台服务。
