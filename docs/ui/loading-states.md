# 知识画布加载态

知识库资源、文档权限确认、文档元数据及正文会话加载共用 `CanvasSpinner`。加载态直接放在当前画布的留白中，不添加图标底座、外框、卡片背景或阴影；错误、无权限及登录跳转继续使用各自的状态界面。

加载图形由三条 1.5px 的中性细线构成，长度依次为 28／36／22px，以 1600ms 的错位节奏舒展和淡入淡出。仅动画化 transform 与 opacity，不触发布局计算，不新增动画依赖。细线使用 `--ink-soft`，状态文字使用 12px 常规 UI 字体、20px 行高与 `--muted-strong`，随全局主题与字体偏好变化。图形和文字相距 14px，长文案居中换行，窄画布保持 24px 横向留白。

状态文字由调用方传入真实阶段，不虚构完成比例，不延迟权限检查或正文显示；阶段切换沿用同一个加载组件，避免重新播放入场动画。`role="status"`、`aria-live="polite"` 与 `aria-atomic="true"` 通告完整状态，装饰细线对辅助技术隐藏。

`prefers-reduced-motion: reduce` 下取消循环动画，以静态细线表示等待；不强制旋转、位移或闪烁。没有最短展示时间或额外定时器，实际内容就绪即可替换加载态。

验证证据见 [.spec/tasks/canvas-loading.md](../../.spec/tasks/canvas-loading.md)。
