# 账户状态面板

账户菜单中的“个人信息”使用统一目录提供的 FA7 Solid `User` 人物图标。状态入口打开简洁的原生模态框，保留在线、离开、勿扰、忙碌四个内置选项；只显示状态名称与语义色点，移除原子菜单中的多行说明。

“自定义状态”由表情与最多 40 个字符的文字组成。表情经共享 `EmojiPicker`、`EmojiPalette` 与 `Emoji` 渲染，使用当前固定的 OpenMoji 精选集。嵌套表情面板位于模态框同一层，支持检索、分类、键盘选择、Escape 和回焦。第一次 Escape 关闭表情面板，之后才关闭状态模态框。

- 内置状态表示当前设备可用性，自定义表情文字作为账户菜单中的状态展示，两者可同时保存。
- 保存后立即更新菜单和账户可访问名称；“清除状态”清空自定义文字，随后保存会恢复内置状态展示。取消和 Escape 放弃尚未保存的编辑。
- 继续沿用 `fob.identity.presence.<userId>`，持久值扩展为 `{ preference, customStatus }`，兼容原先仅保存内置状态的字符串。读取时过滤空白、超长或损坏的自定义记录。
- 状态按账户隔离并通过 storage 事件同步窗口。换号或退出时，旧账户的状态编辑面板不会向新账户提交。
- 在线时无操作五分钟仍自动显示离开；网络断开显示离线，不改变已保存的可用性和自定义文字。
- 状态是设备界面偏好，不授予权限，也不声明已实现跨设备在线广播。

面板宽 380px、受视口约束，沿用系统中性色、语义状态色、30px 底栏按钮及输入框边框焦点反馈，支持浅色与深色主题。
