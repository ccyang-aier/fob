# 个人资料弹窗

## 入口与编排

账户菜单“个人信息”打开原生模态窗口，保留当前文档、工作页签和 URL。完整个人主页已经废弃，旧链接和恢复标签继续回落知识区。当前设计按 2026-11-03 最新批注增强此前从 Git 恢复的弹窗，不恢复文档、文件夹、收藏或社交关系页面。

窗口宽 560px，正文左右 28px；窄屏受视口宽高约束，窗口自身可滚动。顶部 120px 封面直接复用登录的 AuthBackdrop：相同蓝白 horizon、ASCII 字符、鼠标扰动与点击波纹，不另做近似背景。72px 头像悬浮于封面下沿。

正文依次为昵称、邮箱／验证与真实状态、签名、四项统计、六个月活动热图和已获得勋章。统计采用图标在左、数字和标签在右的紧凑组合；桌面四栏、窄屏两栏，无背景、外框或圆角容器，仅保留底部分隔线。图标直接使用语义色，不另加背景；累计学习的数字旁显示分钟。不在默认浏览状态显示表单框或底栏保存按钮。

## 原地编辑

昵称和签名默认只读，以 muted 文字呈现。点击字段或右上角铅笔进入编辑，输入仍无外框、底色、阴影或输入容器；编辑字段宽 260px，并受所在行可用宽度约束，聚焦时显示浅灰色的 control-border 下划线。校验错误仍显示语义红色。不再显示编辑说明小字。邮箱保持已验证账户信息。编辑模式右上角提供取消和保存，Enter 保存，Escape 放弃编辑并保留资料窗口。浏览模式的 Escape 和关闭按钮关闭窗口。

名称与签名一次提交，签名允许为空、最多 160 字符且单行；名称沿用 1–120 字符校验。提交使用现有 cookie 认证更新接口，服务端重验输入，客户端同步去重、阻止提交中关闭，失败保留草稿，成功刷新会话并显示统一 Toast。刷新后恢复持久内容，未保存草稿不冒充真实资料。

## 头像选择与上传

头像 hover／键盘焦点显示相机图标，点击打开独立二级原生弹窗；触控显示小号相机提示。第二层宽 480px，Escape／取消只关闭头像选择，返回资料页，不丢弃资料编辑草稿。

- 内置 24 个独立生成的头像：萌宠、简笔画、风景各 8 个。保留分组间距及无障碍分类名称，删除可见的分类小字。使用本地 256px WebP，总体约 235 KiB；资源与 SHA-256 摘要位于 public/avatars/v1/，来源为为 Fob 生成的 imagegen 作品，不混入系统图标或 Emoji 集。
- 选择仅更新预览，点击“使用此头像”才保存；支持恢复默认首字母头像。
- 上传支持 JPG、PNG、WebP，原文件最大 5 MB，自动居中裁为方形。浏览器移除原始元数据，归一为 192px 静态 WebP，并控制编码体积；取消不会上传。
- 服务端保留 16 KiB 认证请求上限，检查 WebP 文件头、尺寸和动画标识；仅接受小型内联头像或受信任 Web origin 下的指定内置头像。拒绝任意远程图片、SVG、脚本 URL 和超限内容。图片更新后会话、侧栏及成员目录沿用真实 image 字段。
- 临时处理和失败状态均可见，提交去重，关闭或切号后不把迟到预览写回新实例。

签名保存于 auth.user.signature；既有数据库通过显式的 additive upgrade-account-profile.ts 增加字段，不重置账户或知识数据。初始化 current.sql 由 Drizzle 同步生成。头像使用已有 auth.user.image，不新增对象存储或公开上传服务。

## 统计与活动

四项统计不混淆范围：文档为当前知识库内自己创建且仍可访问的文档；收获咖啡仅为他人赠送给自己的累计数量，不包含签到奖励或账户余额；收获点赞为当前知识库内自己评论累计收到的他人点赞；累计学习为当前知识库内真实前台阅读和编辑的活跃分钟。Tooltip 说明口径。收获咖啡通过独立的 receivedCoffeeTotal 字段提供；当前尚无赠送记录来源，服务端与本机均返回 0，不从签到账本或余额补数。未获取数据时使用占位并提供恢复入口。服务端分别返回当天 receivedLikes 与累计 receivedLikesTotal，累计值不受日期筛选影响。

学习计时从功能启用后开始，不根据浏览次数或历史文档时间估算。只有当前活动文档、浏览器可见且拥有焦点、最近 90 秒有交互并且未打开模态窗口时累计；15 秒提交一次，休眠或后台间隔不补算。服务端重验知识库成员与页面 ACL，以同一主体的串行锁和服务端经过时间约束秒数，防止并发页签重复计时；统计仅汇总当前仍可访问文档的秒数并向下取整为分钟。本机知识库只写入 Fob 的独立浏览器命名空间，不上传；浏览器锁限制多实例重复累计。既有数据库须执行 `bun --env-file=.env.fob.local backend/server/scripts/upgrade-profile-learning.ts`，只增加 document_visit 的秒数与心跳字段及约束，保留原数据。

热图为滚动六个月、周日对齐，日期统一 Asia/Shanghai；正确处理月末和闰年，边缘填充及未来日期不可点击。标题仅汇总窗口内数量，方格按可用宽度铺排、间隔 3px。悬停显示日期与总数；点击或键盘确认显示发布文档、发表评论、点赞评论、订阅内容四类真实日计数。明细删除重复的总活动次数一行，图标仅保留语义色，不包背景容器。方向键和 Home/End 导航日期，Escape 先关闭明细。浮层保持在原生模态层内。

资料页只显示最近获得的至多六枚勋章，以图案在上、名称在下的紧凑组合呈现；右侧“更多”打开二级原生勋章墙，点击已获得勋章直接定位详情。桌面勋章墙宽 840px，右侧面板至少高 520px，整体约 620px；左侧完整呈现 18 枚收藏，系列标题和分组计数不再显示，分组名称仅保留无障碍语义。右侧为当前勋章、条件、真实进度与获奖时间线；720px 以下折为上下结构。网格徽章直径 32px，资料页 36px，详情预览 44px；所有等级统一沿用知识园丁的圆形金属硬币、内圈和绶带，只通过内容图形、系列配色和级别标记区分，不再使用方形或盾形外框。网格仅选中项显示共享中性反馈，已获得带小号对勾；未获得保留低饱和系列色与压印质感。减少动态效果时禁用掠光动画。

共享纯契约 `profileMedalCatalog` 同时定义前后端的 18 个稳定 ID、系列、门槛和等级，旧三枚 ID 保留。收藏支持“全部／已获得”筛选；完整目录与门槛如下：

| --- | --- | --- | --- | --- |
| 创作 | 知识园丁 | 妙笔生花 | 知识匠人 | 创建 1／10／50 篇文档 |
| 坚持 | 持续创作 | 日积月累 | 百日耕耘 | 连续 7／30／100 天知识活动 |
| 分享 | 乐于分享 | 灵感使者 | 知识灯塔 | 公开分享 1／5／20 篇自己的文档 |

| 共鸣 | 初获共鸣 | 广受赞许 | 声望之星 | 评论获得 1／10／50 个他人点赞 |

右侧详情使用独立浅底材质：上方采用小号圆形勋章在左、名称／条件／状态在右的紧凑编排，缩短原来纵向预览占用；真实进度与获得日期位于其下。获奖区按获得时间升序组织头像、姓名和时间，并标记最早可见的获得者。行高 40px，默认保留五行可见空间，超出后在独立列表区域纵向滚动；更多页的入口也位于列表滚动区内。实际不足五人时只显示真实记录。移除底部权限说明小字及对应分隔线，权限过滤继续由服务端执行。真实总人数独立于分页返回；不以当前页长度冒充总人数。加载用头像和文本骨架，失败使用 AppAlert 与重试，空态明确尚无可见记录。

获得时间取达到门槛的第 N 条真实事件，连续活动取首次达到指定连续日数的活动时间；连续活动结束后仍保留已达成的历史里程碑。分享按不同文档去重，同一篇的多条有效链接不重复累计；共鸣排除自己的点赞。所有投影先按当前查看者的页面 ACL 过滤；资源删除、撤权、分享撤销或过期后相应投影不再显示。仅列当前知识库成员，guest 只能查看自己的记录，不能借此枚举成员。本机仅计算可用的创作和坚持，其他网络条件保持 0，不模拟网络成员与分享历史。没有历史时间依据的内容不估算获得时间。

## 组件与边界

AccountDialog 区分认证和资料意图；AccountProfile 负责身份摘要与保存，AvatarPicker 负责第二层选择及上传预览，AccountProfileStatistics 和 AccountProfileActivity 组合统计、热图与勋章，MedalWall 负责第二层收藏与获奖记录。knowledge/profile 负责当前主体／知识库摘要、日历运算及前台计时，沿用既有查询失效前缀。

GET discovery/profile 继续先验证知识库成员、主体、令牌和资源 ACL，日聚合独立于活动分页。累计点赞沿用相同可见资源条件；本机不模拟缺少的互动数据或隐式上传。侧栏收起只隐藏入口，保持打开的资料实例。设计及验证记录见 [实施记录](../../.spec/tasks/personal-profile.md)。
