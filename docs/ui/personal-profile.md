# 个人主页

## 定位与入口

个人信息入口打开工作台中的完整个人主页。shell 继续拥有系统侧栏、工作页签、前后退、分屏和恢复；个人主页没有内部标签栏，也不新增第二套导航。设置关闭后返回个人主页。尚未选择知识库时仍能查看和编辑账户资料，资源区域提供选择或新建知识库的入口。

Fob 不引入成员关注和粉丝功能，个人主页不展示这两项统计、入口或占位状态。内容订阅仍属于现有知识资源能力，与成员关系无关。

## 当前页面设计

2026-11-02 用户修订取代旧版四标签和资源卡片方案。页头保留真实头像、状态、昵称、账号标识、当前知识库范围、编辑入口及文档／文件夹数量。删除固定简介和重复荣誉标签。统计数字使用 28px、较强字重；正文仍沿用系统 13px，头像 76px、昵称 24px、操作按钮 32px，不缩放整个页面。

桌面主区域与右栏分开，间距 24px，右栏宽 288px。主区域顶部为全年活动热图；下方等宽分成两列，左侧活动时间线、右侧我的文档。右栏只有独立的“这一天”和“荣誉墙”卡片，间距 16px，不再包在一个大卡片中。旧我的文件夹、收藏与关注卡片全部删除。

### 热图与时间线

- 热图展示近 365 天、53 周。方格按实际容器计算为 9–16px，横纵间隔固定 3px，充分使用可用宽度；不填造活动。窄屏仅图表自身横向滚动并定位到最新日期。
- 悬停提示日期和总数；点击、Enter 或 Space 打开当天明细浮层，展示发布文档、发表评论、点赞评论、订阅内容四类真实数量。打开浮层保留概览；“查看当天活动”显式筛选时间线及每日摘要，“全部活动”清除筛选。外点和 Escape 关闭浮层，方向键及 Home/End 导航日期。
- 时间线按日期分组，采用 1px 细轴、7px 实心灰节点、等宽时间及语义彩色动作图标。时间和动作在上，文档预览或对象标题与真实评论在下，避免宽幅横排。创建动态标题只在预览出现一次，附真实作者；评论内容使用轻量引用样式，不补造摘要或互动。
- 预览复用共享资源卡片材质，无阴影或悬浮位移。菜单位于当前半栏右侧，桌面悬停／键盘进入时显示，窄屏及触控始终可见。文档打开仍交由当前知识导航所有者。

### 我的文档

参考用户的简约文档条目图，改为竖向堆叠，不使用富指标大卡片。标题区显示图标、我的文档和真实总数；每行展示已有文档图标、名称、真实星标、更新时间及已有阅读量。缺少文件字节数时不伪造大小。内容和相邻三点菜单共用一个整行反馈面，保留独立的打开及菜单按钮。

默认展示前 6 条；有更多内容时提供纯文字“查看全部／收起”。文档每批 40 条，展开后可继续“加载更多文档”，有独立忙碌、错误及重试反馈。文档和活动分页分别推进，日期筛选不重置文档分页；初次请求直接供应两列，额外文档页只在需要时请求。菜单复用打开、星标和内容订阅能力，不新增原生排序框或搜索工具栏。

### 每日摘要与荣誉

“这一天”显示今天或所选日期的发布数、评论数、收到的喜欢。收到的喜欢与给出的点赞分别计算。荣誉墙根据真实条件计算知识园丁（创建至少 1 篇文档）、持续创作（连续活跃 7 天）、乐于分享（至少公开分享 1 篇文档），分别展示已获得／待解锁和进度；不把计算条件伪装成颁奖记录。

### 资料编辑、滚动与自适应

编辑资料打开原生模态窗口，复用现有认证服务更新名称、会话刷新、字段校验、重复提交防护、错误及统一 Toast。显示真实头像、名称、邮箱与验证状态；保存／取消按钮 30px。初始聚焦名称，取消、Escape 或点击遮罩可关闭并回到入口，请求期间阻止重复提交与关闭。个人主页本身始终为完整工作页面。

页面根部使用完整纵向滚动容器及 `data-page-scroll="personal-profile"` 接入工作台恢复；不把时间线放入新的内嵌滚动区。Ctrl/Meta + Home/End 保留原生翻页。可用内容宽度低于 1040px 时两张右栏卡片下移，低于 700px 时活动与文档依次排列，低于 500px 时页头操作和统计换行；热图独立横向滚动，其余内容无横向溢出。加载、空态、错误、菜单、键盘焦点、深浅主题沿用共享控件与交互令牌。

## 数据与组件边界

`identity/profile` 管理页头、活动日历、分日时间线、文档列表、每日摘要和独立荣誉墙；账户编辑仍复用 `identity/components/account-profile`。`knowledge/profile` 提供本机／服务端资源适配、独立分页及纯日历运算。前端不导入后端运行时代码。

`GET /api/knowledge/:knowledgeBaseId/discovery/profile` 只查询当前认证主体，读取前验证成员资格和令牌范围。文档、评论、评论点赞、订阅、文件夹与计数先过当前 ACL 和修订检查；回收或权限重建中的内容不泄露标题及统计。收藏 ID 只是偏好候选，不能授予权限；用户 ID 参数不能切换主体。缓存和本机分页均绑定当前知识库与主体。

全年每日四类数量、活动总数和文档总数独立于分页；明细不从当前页推算。活动是当前创建、评论、点赞和订阅记录的投影，不是只增审计日志。本机库只从可证明的创建时间生成活动，不把更新时间当历史事件，不模拟缺少的评论或订阅，不隐式上传。日期及日统计统一 Asia/Shanghai。
