# 个人主页

个人信息入口打开 `?view=profile` 的完整工作台页面。shell 继续拥有系统侧栏、页签、前后退、分屏和恢复；个人主页不新增第二套导航。设置弹层关闭后返回个人主页。尚未选择知识库时仍能查看和编辑账户资料，资源区域提供选择或新建知识库的入口。退出、切号和切库沿用现有主体及知识库作用域隔离。

## 页面与交互

参考用户提供的个人主页 UX：顶部为头像、状态、昵称、账号标识、荣誉及统计；下方为活动、文档、文件夹、收藏四个标签。活动视图采用约 7:3 双栏，左侧展示绿色活动日历及分日时间线，右侧展示所选日期摘要、我的文档、我的文件夹和收藏与关注。窄屏将右栏移到主内容下方，热力图仅在自己的容器内横向滚动。

- 个人页沿用系统 13px 正文尺度，头像 76px、昵称 24px、普通操作 32px；不使用页面缩放或独立的大字号体系。
- 热力图固定展示近 12 个月（365 天、53 周）。方格为 9–14px，横纵间隔固定 3px，不将周列两端拉开；方格按实际图表宽度等比例计算，常用桌面宽度铺满可用空间。日期提示包含真实活动数，点击日期筛选时间线与摘要，再次点击或“全部活动”清除筛选。方向键、Home/End、Enter 和 Space 均可操作。边界补位不参与计数，窄屏独立滚动并默认定位到最新日期。
- 文档提供服务端搜索、排序和增量分页；文件夹、收藏及关注内容提供名称筛选和排序。菜单复用打开、收藏和订阅能力。跨功能资源跳转保留当前知识导航所有者和浏览历史。
- 编辑资料在页面内展开，复用认证服务更新名称、服务端会话刷新与统一 Toast。保留校验、重复提交防护、失败重试、取消及 Escape；不会打开旧个人资料弹窗。
- 荣誉由真实条件计算：创建文档、连续活跃 7 天、公开分享文档。未达成时显示待解锁状态和进度，不伪造奖励。
- 成员关注、粉丝、咖啡赠送和个人简介服务尚未存在。关注与粉丝使用“—”并提供明确状态页；内容订阅正常工作。页面固定副标题是界面文案，不作为用户填写的简介。已有头像沿用账户数据，缺省使用共享首字头像。
- 加载、筛选中、空态、错误、菜单、键盘焦点和深浅主题遵循共享控件与交互令牌。日期与每日统计统一采用 Asia/Shanghai。

## 数据和组件边界

`identity/profile` 管理展示及交互，拆分为页头、活动日历、时间线、侧栏摘要和资源列表。`knowledge/profile` 提供统一的本机／服务端资源适配及纯日历运算；前端不导入后端运行时代码。

服务端 `GET /api/knowledge/:knowledgeBaseId/discovery/profile` 仅查询当前认证主体。读取前重新验证成员资格、令牌作用域；所有文档、评论、评论点赞、订阅、文件夹、收藏候选和计数都先经过当前页面 ACL 与修订检查。回收或权限重建中的页面不会泄露标题及统计。客户端传入的收藏 ID 是偏好候选，不能授予访问权限；用户 ID 查询参数不能切换主体。

活动来源为真实的创建、评论、评论点赞及当前订阅记录。文档和活动每批 40 条；热力图、完整日计数、个人文档总数独立计算，不受分页或名称筛选影响。取消订阅、删除评论或撤回点赞后相应投影记录消失；此页面是当前业务数据的活动投影，并非只增审计日志。

本机资源仍属于浏览器本地库，不因登录而改变归属。页面明确标注本机范围，仅从可证明的创建时间生成活动，不把最后更新时间伪装成历史事件；资料、资源和缓存不会隐式上传。本机库缺少服务端订阅和评论能力时不模拟结果。
