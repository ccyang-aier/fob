# 个人资料弹窗

## 入口与编排

账户菜单“个人信息”打开原生模态窗口，保留当前文档、工作页签和 URL。完整个人主页已经废弃，旧链接和恢复标签继续回落知识区。当前设计按 2026-11-02 最新批注增强此前从 Git 恢复的弹窗，不恢复文档、文件夹、收藏或社交关系页面。

窗口宽 560px，正文左右 28px；窄屏受视口宽高约束，窗口自身可滚动。顶部 120px 封面直接复用登录的 AuthBackdrop：相同蓝白 horizon、ASCII 字符、鼠标扰动与点击波纹，不另做近似背景。72px 头像悬浮于封面下沿。

正文依次为昵称、邮箱／验证与真实状态、签名、三项统计、六个月活动热图和已获得勋章。不包多层卡片，不在默认浏览状态显示表单框或底栏保存按钮。

## 原地编辑

昵称和签名默认只读，以 muted 文字呈现。右上角铅笔进入编辑，输入仍无边框、底色、阴影或输入容器；聚焦当前字段时只显示下划线。邮箱保持已验证账户信息。编辑模式右上角提供取消和保存，Enter 保存，Escape 放弃编辑并保留资料窗口。浏览模式的 Escape 和关闭按钮关闭窗口。

名称与签名一次提交，签名允许为空、最多 160 字符且单行；名称沿用 1–120 字符校验。提交使用现有 cookie 认证更新接口，服务端重验输入，客户端同步去重、阻止提交中关闭，失败保留草稿，成功刷新会话并显示统一 Toast。刷新后恢复持久内容，未保存草稿不冒充真实资料。

## 头像选择与上传

头像 hover／键盘焦点显示相机图标，点击打开独立二级原生弹窗；触控显示小号相机提示。第二层宽 480px，Escape／取消只关闭头像选择，返回资料页，不丢弃资料编辑草稿。

- 内置 24 个独立生成的头像：萌宠、简笔画、风景各 8 个。使用本地 256px WebP，总体约 235 KiB；资源与 SHA-256 摘要位于 public/avatars/v1/，来源为为 Fob 生成的 imagegen 作品，不混入系统图标或 Emoji 集。
- 选择仅更新预览，点击“使用此头像”才保存；支持恢复默认首字母头像。
- 上传支持 JPG、PNG、WebP，原文件最大 5 MB，自动居中裁为方形。浏览器移除原始元数据，归一为 192px 静态 WebP，并控制编码体积；取消不会上传。
- 服务端保留 16 KiB 认证请求上限，检查 WebP 文件头、尺寸和动画标识；仅接受小型内联头像或受信任 Web origin 下的指定内置头像。拒绝任意远程图片、SVG、脚本 URL 和超限内容。图片更新后会话、侧栏及成员目录沿用真实 image 字段。
- 临时处理和失败状态均可见，提交去重，关闭或切号后不把迟到预览写回新实例。

签名保存于 auth.user.signature；既有数据库通过显式的 additive upgrade-account-profile.ts 增加字段，不重置账户或知识数据。初始化 current.sql 由 Drizzle 同步生成。头像使用已有 auth.user.image，不新增对象存储或公开上传服务。

## 统计与活动

三项统计不混淆范围：文档为当前知识库内自己创建且仍可访问的文档；获得咖啡为账户真实签到账本的累计获得数；收获点赞为当前知识库内自己评论累计收到的他人点赞。Tooltip 说明口径，未获取数据用缺省占位并提供既有恢复入口，不填造赠送咖啡或文档点赞。服务端分别返回当天 receivedLikes 与累计 receivedLikesTotal，累计值不受日期筛选影响。

热图为滚动六个月、周日对齐，日期统一 Asia/Shanghai；正确处理月末和闰年，边缘填充及未来日期不可点击。标题仅汇总窗口内数量，方格按可用宽度铺排、间隔 3px。悬停显示日期与总数；点击或键盘确认显示发布文档、发表评论、点赞评论、订阅内容四类真实日计数。方向键和 Home/End 导航日期，Escape 先关闭明细。浮层保持在原生模态层内。

勋章只显示真实条件已满足的知识园丁、持续创作、乐于分享，使用本地 OpenMoji；不展示未解锁占位，不编造颁发时间或历史。无勋章时显示真实空态。

## 组件与边界

AccountDialog 区分认证和资料意图；AccountProfile 负责身份摘要与保存，AvatarPicker 负责第二层选择及上传预览，AccountProfileStatistics 和 AccountProfileActivity 组合统计、热图与勋章。knowledge/profile 负责当前主体／知识库摘要与纯日历运算，沿用既有查询失效前缀。

GET discovery/profile 继续先验证知识库成员、主体、令牌和资源 ACL，日聚合独立于活动分页。累计点赞沿用相同可见资源条件；本机不模拟缺少的互动数据或隐式上传。侧栏收起只隐藏入口，保持打开的资料实例。设计及验证记录见 [实施记录](../../.spec/tasks/personal-profile.md)。
