# 个人资料弹窗

## 入口与恢复来源

2026-11-02 用户决定恢复完整个人主页之前的弹窗。以 Git `7e67995`（`6464c2a` 引入完整个人页之前）为视觉和结构基线，恢复灰色流动封面、悬浮头像、身份摘要、资料表单和底栏。只选择性恢复个人信息体验，不回退后续知识库成员与权限能力。

侧栏账户菜单的“个人信息”直接打开原生模态窗口，不改变当前文档、工作页签或 URL。废弃完整个人页、内部标签、时间线、资源列表、每日摘要与荣誉墙侧栏。旧 `view=profile` 链接回到知识区，保留知识库和文档参数；恢复工作台时过滤旧个人页标签及其分屏，保留有效文档实例。Fob 继续不引入关注和粉丝功能。

## 当前编排

窗口沿用原版 440px 宽、100px 灰色封面、62px 头像与 22px 圆角。封面恢复原有本地 Canvas 丝带，不加载远端图片；隐藏时暂停，减少动态效果时静态绘制。小屏宽度受视口约束，高度不足时窗口自身滚动。

内容依次为真实昵称、邮箱／验证状态、当前状态，显示名称输入，六个月活动热图，已获得勋章。邮箱在摘要中显示一次，名称仍通过现有认证接口编辑。底栏取消／保存按钮统一 30px；未修改或空值不可保存，字段失焦显示校验。提交去重，提交期间阻止关闭，失败保留输入并显示错误，成功刷新真实会话并使用统一 Toast。

只有账户菜单明确请求个人资料时才装载资料内容。全局登录／切换账户窗口继续渲染原有认证界面，不因已认证会话意外请求知识库资料。侧栏自动收起仅隐藏账户入口，保留其弹窗实例，调整视口不会丢失打开的资料表单。

## 六个月活动与勋章

- 热图使用滚动六个月日期窗口，按自然月运算并处理月末、闰年；周日对齐，边缘填充与未来日期不可点击。日期统一 Asia/Shanghai。标题总数只汇总当前窗口，不能用全年总数代替。
- 方格依窗口宽度计算，固定 3px 间隔，沿用五档绿色及深色对应色。正常桌面和约 410px 小屏均完整排入窗口；更窄时只允许图表自身横向滚动。
- 悬停显示日期和总数；点击或键盘确认打开当日四类明细：发布文档、发表评论、点赞评论、订阅内容。浮层在原生模态层内定位；Escape 先关闭明细并返回日期，之后才关闭资料窗口。方向键、Home/End 导航日期，不拦截系统组合键。
- 勋章只显示按真实条件已获得的项目：创建至少一篇文档的“知识园丁”、连续活跃七天的“持续创作”、至少公开分享一篇文档的“乐于分享”。使用本地 OpenMoji，提示显示真实计数；不展示未解锁项目，不编造颁发时间或奖励记录。没有勋章时呈现真实空态。

## 数据与组件边界

`identity/components/account-profile` 负责原版资料内容和保存；`account-profile-activity` 组合热图与已获得勋章；`identity/profile` 只保留活动日历、明细和文案。`knowledge/profile` 提供摘要适配与纯日历运算。查询仅在弹窗打开期间存在，绑定当前知识库与主体；无知识库、加载、失败及重试分别呈现。

继续使用 `GET /api/knowledge/:knowledgeBaseId/discovery/profile` 的真实聚合，在客户端截取六个月。服务端在读取前验证成员资格、令牌和资源 ACL；日计数独立于分页，不从当前活动页推算。本机只使用可证明的创建时间，不把更新时间、示例评论或点赞填成活动，也不隐式上传。

执行与当前验证证据见 [个人资料弹窗实施记录](../../.spec/tasks/personal-profile.md)。
