# AI 接入设置

AI 接入管理当前账户在当前知识库中的模型服务与快速 / 深度默认模型。连接、凭据、请求与权限规则见 [知识助手架构](../knowledge-assistant-agent.md)，本页维护当前界面设计。

## 布局与层次

- 沿用设置弹窗、导航、字体和中性色令牌；内容最大宽度 880px。标题 22px，分区标题 14px，主要内容 13px，控件 12px，辅助信息 11–12px。
- 标题下集中展示真实账户 / 知识库作用域。默认模型、模型服务、用量三个分区使用统一对齐线和 28px 节奏，不加装饰性横幅或背景图片。
- 默认模型放入单个轻描边组，每个档位一行。左侧是统一目录的语义图标、名称与用途，右侧是复用的可搜索模型选择器；选择器常态去掉重复内框，交互仍使用共享反馈，键盘焦点保留边框。
- 只有服务端默认连接时直接展示只读服务面板。存在个人连接或正在添加连接时，才显示横向、可滚动的服务切换条；不留下空的左列。
- 服务端面板展示真实快速 / 深度模型和只读标记；未配置时明确提示。个人服务面板沿用名称、协议、Base URL、密钥、模型读取与编辑、测试、保存和确认删除。
- 用量使用无额外卡片的三列数字排版：小号标签、24px 等宽数字、轻分隔线；数据完全来自当前账户与知识库的真实累计。

## 响应式与状态

窄屏中默认模型的说明和选择器纵向排列，表单字段单列，模型行把 ID 单独放到上方；名称、测试与删除保持可操作。用量数字缩为 20px，沿用共享设置滚动容器，不产生页面横向溢出。

浅深色共用同一套结构及全局材质。没有新字体、图标包、图片资源或交互配色；保存忙碌、空态、加载、认证、权限变化和错误恢复继续复用原控制器与共享控件。密钥不进入浏览器存储，切换服务或作用域仍卸载草稿；视觉改动不触发连接保存或测试。

验证记录见 [AI 接入设置改版](../../.spec/tasks/ai-connections-design.md)。
