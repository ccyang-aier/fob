# AI 接入设置

AI 接入管理当前知识库统一使用的模型服务与快速 / 深度默认模型。管理员配置一次，所有成员直接使用；连接、凭据和默认模型均归知识库所有。连接、凭据、请求与权限规则见 [知识助手架构](../knowledge-assistant-agent.md)，本页维护当前界面设计。

## 管理权限

- 仅当前服务端知识库的所有者（`owner`）和管理员（`admin`）可见并配置 AI 接入。编辑者、查看者、访客、未登录用户、本机知识库及权限加载期间不挂载该菜单和配置面板；设置搜索与窄屏导航遵循相同规则。
- 无权限的 `section=ai` 直达链接显示外观设置。切换知识库或权限变化后立即卸载配置面板，中止其请求；煤球更多菜单和未配置提示也不提供设置入口。
- 配置面板使用受管理权限保护的 `GET /assistant/configuration`。连接新增、修改、删除、模型发现、测试、默认模型与旧版设置写入均重新验证当前知识库成员身份和角色，无权限返回 403；业务服务同步检查配置权限。
- `GET /assistant/settings` 供成员读取当前知识库的模型就绪状态和可选模型。连接、密钥、默认模型、24 个连接限额及保存锁均以知识库隔离；管理员可维护彼此建立的连接，创建者离开也不影响使用。会话、历史及页面授权仍按真实用户和知识库隔离。

## 布局与层次

- 沿用设置弹窗、导航、字体和中性色令牌；内容最大宽度 880px。标题 22px，分区标题 14px，主要内容 13px，控件 12px，辅助信息 11–12px。
- 标题下展示当前知识库及「由管理员统一配置，所有成员共享使用」。默认模型、模型服务、用量三个分区使用统一对齐线和 28px 节奏，不加装饰性横幅或背景图片。
- 默认模型放入单个轻描边组，每个档位一行。左侧是统一目录的语义图标、名称与用途，右侧是复用的可搜索模型选择器；选择器常态去掉重复内框，交互仍使用共享反馈，键盘焦点保留边框。
- 只有服务端默认连接时直接展示只读服务面板。存在知识库自定义连接或正在添加连接时，才显示横向、可滚动的服务切换条；不留下空的左列。
- 服务端面板展示真实快速 / 深度模型和只读标记；未配置时明确提示。知识库服务面板沿用名称、协议、Base URL、密钥、模型读取与编辑、测试、保存和确认删除；删除提示说明影响全库成员。
- 用量使用无额外卡片的三列数字排版：小号标签、24px 等宽数字、轻分隔线；展示当前知识库「所有成员累计」，底层调用记录继续保留实际使用者。

## 响应式与状态

窄屏中默认模型的说明和选择器纵向排列，表单字段单列，模型行把 ID 单独放到上方；名称、测试与删除保持可操作。用量数字缩为 20px，沿用共享设置滚动容器，不产生页面横向溢出。

浅深色共用同一套结构及全局材质。没有新字体、图标包、图片资源或交互配色；保存忙碌、空态、加载、认证、权限变化和错误恢复继续复用原控制器与共享控件。密钥不进入浏览器存储，切换服务或作用域仍卸载草稿；视觉改动不触发连接保存或测试。
