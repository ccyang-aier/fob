# 文档块拖拽

本地文档、协作文档与文件夹内联正文共用 `DocumentEditorContent` 的拖拽层。浮动按钮位于编辑内容之外；只读时隐藏，悬停正文时显示官方 FA7 六点图标。24px 操作区域位于块左侧，与首行垂直居中；标题原有级别提示在手柄出现时让位。没有新增图标依赖或文档属性。

拖动时由浏览器显示原块的原生预览，源块降低不透明度。按用户提供的 Outline 参考，正文块插入线使用独立蓝色反馈（浅色 `#0869cf`、深色 `#8cc7ff`），不改变系统其他拖拽令牌。指示线随滚动更新，滚动容器边缘支持自动滚动。

段落、标题、引用、提示框、代码、媒体与整张表格按顶层块移动；列表项可在所属列表内调整顺序。目标吸附到同父节点的块边界，禁止插入段落中间、跨编辑器移动或拖进不同容器。文档只有一个块时拖放不产生内容变更。取消拖动、移出有效区域、权限变为只读、切换文档或卸载编辑器时清理手柄、预览与指示线。

移动通过单次 ProseMirror 事务删除并重新插入同一个节点，保留内容、后代与所有块 ID，复用本地历史或 Yjs 协作历史。悬停与拖动状态只属于插件，不进入文档 JSON、导出 HTML、持久化或协作数据。键盘仍可通过既有的 `Mod+Shift+↑/↓` 调整当前块。

验证证据见 [.spec/tasks/editor-block-drag.md](../.spec/tasks/editor-block-drag.md)。
