# 文档块手柄与拖拽

本地文档、协作文档与文件夹内联正文共用 `DocumentEditorContent` 的拖拽层。浮动按钮位于编辑内容之外；只读时隐藏，悬停正文时显示官方 FA7 六点图标。24px 操作区域位于块左侧，与首行垂直居中；标题原有级别提示在手柄出现时让位。没有新增图标依赖或文档属性。

列表项手柄位于所属列表的外侧，避开圆点、编号及任务复选框；从文字移过标记区到手柄时保持当前列表项，不切换成整组列表。表格按第一行的实际中心定位；光标进入表格、表格菜单打开或行列控件激活时隐藏整块手柄，通过选择状态及控件标记同步避让。提示框、代码等带工具区的节点按内容首行对齐；包含表格的其他容器不会被误判成整张表格。

六点手柄支持点击与拖动。点击打开共享 Radix 块菜单；原生拖拽保留在实际按钮上，菜单使用不接收指针的定位锚点，避免下拉触发器在 pointerdown 阶段阻断拖动。菜单使用 208px 主菜单、184px 转换子菜单、18px 圆角和 32px 操作行；图标复用系统默认 FA7 Solid 与已登记的控制/编辑符号，采用菜单尺寸；“在下方插入”的加号按用户要求大一档，实际 14px，颜色、危险反馈、分隔线、阴影及多级菜单高亮继续来自共享控件。靠外点、再次点击手柄或 Escape 关闭；Escape 回焦到手柄。菜单打开期间固定目标，跟随位置映射；目标被删除、编辑权限丢失或编辑器卸载时关闭。

“转换为”提供正文、标题 1–4、无序/有序/待办列表、引用、提示框与代码块。操作按稳定块 ID 重新定位，只转换点击的列表项；必要时拆分所属列表并维持两侧编号、相邻行及嵌套内容。原块 ID 保留在转换后的对应块，不复制成重复 ID。不能保留原内容的转换禁用，例如媒体块转正文或含行内公式的段落转代码；不以空块或纯文本冒充转换成功。选择当前类型只关闭菜单，不切换成其他类型。

“在下方插入”在目标后创建空段落；列表中创建同类的空列表项，再打开现有插入菜单。“删除”删除整块，最后一个列表项会连同空列表容器移除，文档最后一块删除后保留可继续书写的合法段落。转换、插入、删除使用单次事务，并隔离本地和 Yjs 撤销批次，支持单步撤销与重做；只读状态不接受这些操作。

“复制链接”使用文档所在知识库、来源、页面和稳定块 ID 生成 `?view=knowledge&document=…&knowledgeBase=…&source=…&block=…` 链接，去除无关页签和设置状态。打开后等待对应编辑器正文就绪，再复用既有块定位与短暂高亮。文件夹内联概览没有独立页面身份，因此明确禁用该操作。剪贴板成功和真实拒绝通过全局 Toast 反馈。

菜单底部展示该块最近记录的真实编辑者与时间。协作服务在既有知识库/页面 ACL 连接内，从认证后的成员资料记录变更，保存在同一 Y.Doc 的 `fob:block-edits` Map 中，随现有文档持久化与同步；不新增数据库或正文 schema 属性。本机正文与 `blockEdits` 在同一次本机资源更新中保存。记录带有内容指纹；旧内容无记录，或正文已被其他写入路径更新而记录不匹配时，显示“暂无此块的编辑记录”，不推测创建者或使用当前时间。该信息用于编辑界面展示，不作为权限或审计凭据。

空白书写行（包括仅含空格或换行的段落、标题）不显示六点拖拽图标，也不能从旧手柄启动拖动。悬停时显示已有 Lucide `Plus` 和本地化的“输入 '/' 来插入…”提示；点击加号打开现有内容插入菜单，以零长度触发范围定位，不往正文写入 `/`。取消菜单不改变正文，选取项目继续使用原有插入命令。空代码块、媒体和行内数学/链接节点不按空白行处理。提示只是节点装饰，不参与 JSON、导出、块 ID 或持久化；标题级别提示为此让位。

拖动时在正文外显示随鼠标移动的内容虚影，保留原块的宽度、字体和抓取位置偏移，使用 65% 不透明度及沿阅读方向渐隐；源块单独降低为 30% 不透明度。跟随层不依赖视口外 DOM 的原生拖动截图，浏览器原生影像使用透明位图，避免出现重复虚影。虚影不可交互且不进入可访问树、文档内容或保存数据。按用户提供的 Outline 参考，正文块插入线使用独立蓝色反馈（浅色 `#0869cf`、深色 `#8cc7ff`），不改变系统其他拖拽令牌。指示线随滚动更新，滚动容器边缘支持自动滚动。

段落、标题、引用、提示框、代码、媒体与整张表格按顶层块移动；列表项可在所属列表内调整顺序。目标吸附到同父节点的块边界，禁止插入段落中间、跨编辑器移动或拖进不同容器。文档只有一个块时拖放不产生内容变更。取消拖动、移出有效区域、权限变为只读、切换文档或卸载编辑器时清理手柄、预览与指示线。

移动通过单次 ProseMirror 事务删除并重新插入同一个节点，保留内容、后代与所有块 ID，复用本地历史或 Yjs 协作历史。悬停与拖动状态只属于插件，不进入文档 JSON、导出 HTML、持久化或协作数据。键盘仍可通过既有的 `Mod+Shift+↑/↓` 调整当前块。

协作撤销管理器由页面会话持有。动态挂载、重新配置或卸载手柄插件时，编辑器视图只解绑自身的撤销监听，不销毁会话管理器，避免拖拽、语言切换和控件重挂载之后丢失撤销/重做；最终销毁仍由页面会话负责。

宽度不超过 600px 时，“转换为”在同一弹层内展示格式列表并提供“返回块操作”，Escape 先返回主菜单；桌面仍使用侧向子菜单。两种模式均限制弹层宽高并允许滚动，避免双层并排菜单在手机视口被裁切。
