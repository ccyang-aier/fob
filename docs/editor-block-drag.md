# 文档块拖拽

本地文档、协作文档与文件夹内联正文共用 `DocumentEditorContent` 的拖拽层。浮动按钮位于编辑内容之外；只读时隐藏，悬停正文时显示官方 FA7 六点图标。24px 操作区域位于块左侧，与首行垂直居中；标题原有级别提示在手柄出现时让位。没有新增图标依赖或文档属性。

列表项手柄位于所属列表的外侧，避开圆点、编号及任务复选框；从文字移过标记区到手柄时保持当前列表项，不切换成整组列表。表格按第一行的实际中心定位；光标进入表格、表格菜单打开或行列控件激活时隐藏整块手柄，通过选择状态及控件标记同步避让。提示框、代码等带工具区的节点按内容首行对齐；包含表格的其他容器不会被误判成整张表格。

空白书写行（包括仅含空格或换行的段落、标题）不显示六点拖拽图标，也不能从旧手柄启动拖动。悬停时显示已有 Lucide `Plus` 和本地化的“输入 '/' 来插入…”提示；点击加号打开现有内容插入菜单，以零长度触发范围定位，不往正文写入 `/`。取消菜单不改变正文，选取项目继续使用原有插入命令。空代码块、媒体和行内数学/链接节点不按空白行处理。提示只是节点装饰，不参与 JSON、导出、块 ID 或持久化；标题级别提示为此让位。

拖动时在正文外显示随鼠标移动的内容虚影，保留原块的宽度、字体和抓取位置偏移，使用 65% 不透明度及沿阅读方向渐隐；源块单独降低为 30% 不透明度。跟随层不依赖视口外 DOM 的原生拖动截图，浏览器原生影像使用透明位图，避免出现重复虚影。虚影不可交互且不进入可访问树、文档内容或保存数据。按用户提供的 Outline 参考，正文块插入线使用独立蓝色反馈（浅色 `#0869cf`、深色 `#8cc7ff`），不改变系统其他拖拽令牌。指示线随滚动更新，滚动容器边缘支持自动滚动。

段落、标题、引用、提示框、代码、媒体与整张表格按顶层块移动；列表项可在所属列表内调整顺序。目标吸附到同父节点的块边界，禁止插入段落中间、跨编辑器移动或拖进不同容器。文档只有一个块时拖放不产生内容变更。取消拖动、移出有效区域、权限变为只读、切换文档或卸载编辑器时清理手柄、预览与指示线。

移动通过单次 ProseMirror 事务删除并重新插入同一个节点，保留内容、后代与所有块 ID，复用本地历史或 Yjs 协作历史。悬停与拖动状态只属于插件，不进入文档 JSON、导出 HTML、持久化或协作数据。键盘仍可通过既有的 `Mod+Shift+↑/↓` 调整当前块。

协作撤销管理器由页面会话持有。动态挂载、重新配置或卸载手柄插件时，编辑器视图只解绑自身的撤销监听，不销毁会话管理器，避免拖拽、语言切换和控件重挂载之后丢失撤销/重做；最终销毁仍由页面会话负责。
