# 编辑器富内容块

## 范围

支持独立表情、链接卡片、Mermaid 与 PlantUML 图表、PDF 内嵌预览、B站视频及 Excalidraw 白板。Figma 等其他平台后续按实际使用需求扩展。全部节点由 `shared` 注册语义，浏览器模块仅负责交互与呈现，沿用稳定块 ID、Yjs、撤销、模板和知识库权限。

| 内容 | 权威数据 | 插入与编辑 |
| --- | --- | --- |
| 表情 | Unicode `value` | `/表情` 或 `/emoji` 插入默认 😀；点击更换，复用 448 个本地 OpenMoji 与搜索、分类、键盘操作；只读仅展示 |
| 链接卡片 | 原链接、标题、摘要、封面地址、来源名称 | `/链接卡片` 或空段落粘贴独立 URL；可转换为普通链接或嵌入，并手动编辑资料 |
| Mermaid | 源码、标题、主题、宽高与自动尺寸状态 | `/mermaid` 或 Markdown mermaid 围栏；beautiful-mermaid 原生渲染与主题、按内容自然宽高、边框外原地编辑标题、块内按需操作组、自然边缘缩放与遮罩放大查看 |
| PlantUML | 源码、标题、宽高与自动尺寸状态 | `/plantuml`、`/puml` 或粘贴 plantuml / puml 围栏；本地引擎渲染、源码编辑、按内容自然宽高、标题编辑、边缘缩放与遮罩放大查看 |
| PDF | 库内附件引用或外部 URL、标题、说明、高度 | `/pdf` 上传或填写链接；既有 PDF 附件也使用阅读器；支持翻页、缩放、下载和全屏 |
| B站 | 原链接、标题、高度 | `/B站` 或网页嵌入；识别 BV、av、官方播放器链接，保留分P与起播秒数，关闭自动播放 |
| 白板 | Excalidraw 场景、PNG 预览快照、标题、宽高与自动尺寸状态 | `/excalidraw`；正文按内容自然宽高、边框外原地编辑标题、按需操作、边缘缩放与遮罩放大、模态画布明确保存/取消、源文件下载 |

## 数据、权限与外部依赖

- PDF 复用本机 IndexedDB 和服务端授权上传、签名下载，不另建公开附件路径。外部 PDF 依赖源站 CORS 与访问权限，失败保留原文件入口。
- 白板场景属于页面正文，包含图元和必要图片，不保存协作者、选中状态等运行时信息。首版限制 2000 个图元及 4 MiB，图片支持 PNG/JPEG/GIF/WebP；外部网页使用独立嵌入块。编辑会话打开后若场景被其他客户端修改，拒绝覆盖并提示重新打开。
- 白板保存时同时生成最长边 1024px、8px 导出留白的 PNG 预览和场景 SHA-256，随页面权限持久化；普通阅读直接显示匹配的快照，源数据被外部修改、旧场景或损坏快照回退到同样使用 8px 留白的场景渲染。已有快照不在读取时重写，预览只接受有界的 PNG data URL。
- Mermaid、PlantUML 与白板的画布区域默认不显示边框，悬停或键盘聚焦时显示统一的 1px 浅色细边框，透明占位避免布局跳动；保留 8px 圆角，预览顶部与左右各留 8px，底部不另加空白。标题作为画布区域的同级元素，位于边框外下方，顶部间隔 4px，居中显示为 12px 常规字重辅助文字；无类型图标、分隔线或标题底色。点击标题原地编辑，不显示输入框或描边，不占满整行；回车或失焦提交，Escape 取消，外部重命名与撤权丢弃旧草稿。纯文本粘贴合并换行，限制 500 字符，中文输入法确认不提前提交。空标题回退到内容类型，只读显示纯文字；HTML 与公共 Markdown 导出保留标题。
- 操作组悬浮在画布边框内部右上角，距上、右边缘各 8px，不占顶部行高；使用 3px 内边距、2px 间距、独立 6px 按钮圆角和单层浅色描边，保留编辑、下载与“放大查看”。悬停、键盘聚焦或标题编辑时显示，鼠标移开后收起，普通鼠标点击不残留高亮；触屏通过点击唤出，工具按钮至少 44px。标题在边框外，不与操作组挤压。
- 默认 `autoWidth=true` / `autoHeight=true`。Mermaid 与 PlantUML 以 SVG viewBox 尺寸计算自然宽度；白板以场景坐标、旋转与图形 / 线段点位计算内容边界，避免把 1024px 快照分辨率当作绘图大小。三类图形均按内容自然宽高展示，小图保持固有大小，超出正文宽度时等比缩小，高度依固有比例自然排布。窄屏、目录开合、侧栏和分屏宽度变化时自动适配容器，无需重新渲染或保存内容。最小操作区域 120px，极小图像本身仍限制在内容宽度内，不被最小外框放大。旧节点缺失字段时同样自动适配，保留原宽高数值，不在读取时主动改写正文。源码编辑的自然宽度约 578px、编辑区域高 360px；空态 / 加载态至少 120px 高。
- 右侧、底部、右下角保留隐形缩放区域，仅在对应方向转为手动尺寸；横向调整保留自动高度，纵向调整保留自动宽度。拖拽从实际呈现尺寸开始，松开后一次写入并可撤销；Escape、指针取消、丢失捕获、远端尺寸 / 自动状态变化及撤权恢复原尺寸与模式。双击边缘或按 Home 恢复该方向自动尺寸，角区恢复两个方向。桌面边缘 10px、角区 20px，向外延伸 3px；触屏分别 16px、32px。只显示方向指针，不增加手柄、图标或反馈线。手动宽度保存为正文宽度 1–100%，并受 120px 最小操作宽度约束；手动整体高度 80–1200px。自动模式无固定高度上限；手动模式完整等比展示，不产生内部滚动。只读不提供尺寸编辑。
- 图形块不再调用浏览器全屏。点击“放大查看”或图像，在居中的原生模态 dialog 遮罩中展示当前预览：桌面宽度为 84vw、上限 1120px，高度为 84dvh、上限 760px，四周保留明显背景空间；窄屏左右各留 16px、高度为 84dvh。预览顶部不保留整行占位，标题独立悬浮在左上角，关闭按钮独立固定在右上角；长标题省略并避让关闭按钮，两者保持在图形上层，不随平移或缩放移动。画布使用弹层四周内边距内的完整区域。初始完整适应弹层可用空间，小图初始最多放大至 3 倍。滚轮以指针位置为中心缩放，按住左键拖拽平移，双击切换放大 / 适配；缩放操作组固定悬浮在弹层右下角，提供缩小、原始尺寸、放大和适应窗口，支持加减键、方向键、0 / Home；删除底部说明文字与整行占位，画布延伸至弹层底部内边距，窄屏同样保留右下角操作组。缩放上限 8 倍，平移保留可见部分，真实视口变化重新适配，控件焦点变化不重置缩放。点击关闭、遮罩或 Escape 退出并回焦；原生 modal 限制背景交互、阻止滚轮穿透，Tooltip 保持在同一弹层。预览不写入正文或修改块尺寸，只读同样可用。
- Mermaid 与 PlantUML 通过“编辑图表”进入源码模式，保留源码即时保存行为；点击“预览”回到完整图表。图形块订阅编辑权限变化，转为只读时关闭标题、源码与尺寸编辑，保留放大预览、下载等阅读操作。
- PlantUML 使用官方 MIT 版 `@plantuml/core` 1.2026.9（TeaVM + Viz.js），无需 Java 或远程渲染服务。构建与开发启动由 `prepare-rich-content.mjs` 将引擎桥接为经典脚本，并准备带版本路径的本地资产；只有出现 PlantUML 块时才加载。每次渲染在仅允许脚本的隐藏 sandbox iframe 中执行，CSP 仅允许本站脚本及 Viz.js 的 WebAssembly 编译，阻断额外联网请求、外部图片、表单及文件读取，父页面只接受对应 frame 和请求 ID 返回的 SVG，并以图片显示，不把生成的 SVG 注入应用 DOM。来源及完整许可见 [PlantUML 许可](../public/licenses/plantuml.txt)，[上游集成说明](https://github.com/plantuml/plantuml/blob/master/PUBLISHING_NPM.md)。
- PlantUML 源码上限为 50,000 字符，SVG 上限为 2,097,152 个字符与 4096px 尺寸，单次超时 15 秒；最多同时渲染两个块，按源码和深浅外观缓存最多 16 份结果，总长度不超过 8,388,608 个字符，过期、取消和失败结果不写入缓存。引擎的语法错误诊断 SVG 转为明确错误状态，修正后可重试；原始源码保留。支持随包提供的主题、Emoji 与 OpenIconic 图形资源，外部 `!include`、本机文件及未打包的 C4 / 云厂商等标准库扩展暂不支持，不向公共服务发送文档源码。源码、标题和尺寸编辑继续服从当前文档权限，撤权立即关闭编辑入口。
- Mermaid 图样使用 [beautiful-mermaid](https://github.com/lukilabs/beautiful-mermaid) 1.1.3 的实际渲染器，采用其 ELK 布局、直角折线、轻描边、箭头、分组标题带和字体层级，画布导出留白收至 8px，替换此前自行调配的 Mermaid Classic 外观。流程、状态、时序、类、ER 和 XY 图由新引擎生成独立 SVG。引擎按需加载，轻量色板模块只保留两套配色；与该版本上游 `THEMES` 做精确一致性回归。
- 只使用 GitHub Light / GitHub Dark 两套原生主题，自动跟随 Fob 已解析的系统浅色 / 深色外观。两者采用中性色画布、清晰文字和少量蓝色箭头强调；图表工具组只提供编辑与放大查看，不保留主题按钮、菜单或单块主题选择。新节点的历史兼容字段默认为 `auto`；旧主题属性继续合法并可导入 / 往返，但不参与渲染，不在读取或切换系统主题时改写正文。标题、宽高、协作及撤销行为保持独立。
- 颜色使用上游 `bg / fg` 与可选 `line / accent / muted / surface / border` 七通道及 `color-mix()` 派生规则，全部随 SVG 保存，不再叠加 Fob 的按形状强制填色。画布预览使用相同背景，字号与几何沿用上游；删除 SVG 的远程字体导入，使用本机 Inter / 系统字体回退，离线不依赖 Google Fonts。SVG 保持在图片上下文中展示。MIT 来源与完整许可见 [beautiful-mermaid 许可](../public/licenses/beautiful-mermaid.txt)。
- 渲染适配仅提取 frontmatter、初始化指令与 `accTitle / accDescr` 元数据，保留可访问标题和说明；文档内原始源码始终保留，旧 Mermaid 专用的主题 / 布局配置不改写新的原生主题体系。节点 `style / classDef` 的上游支持属性继续生效。新引擎未覆盖的图种、扩展形状及无法解析的有效语法按需回退至 Mermaid 严格模式，并使用相同上游色板与派生规则，保留 50,000 字符上限；兼容引擎串行初始化 / 渲染，失败不阻断后续图表。正文、遮罩预览和已渲染 HTML 导出共享同一 SVG；无损 Markdown 保留新旧主题标识，公共 Markdown 保留可重导入的原始源码。
- 白板编辑弹窗仍支持标题，与场景和预览一起显式保存；取消保留原标题和绘图，关闭或销毁后的异步保存不得回写。打开会话后若场景或标题被其他客户端修改，拒绝覆盖并提示重新打开。
- 网页摘要由 Fob 业务服务抓取公开 HTML；`knowledgeBaseId` 与 `source` 明确作用域。服务端库请求校验知识库身份，本机库可匿名获取公开网络资料，接口不查询任何 Fob 文档或资产。只信任 Fob origin，限制速率、并发、超时、重定向和响应大小；每跳检查并固定公网 DNS 地址，不发送源站 Cookie 或执行脚本。
- 卡片元数据保存为正文快照，仅编辑者在插入或重试时获取；只读打开不触发摘要抓取。源站失败支持重试和手动填写，不虚构网页信息。
- 外部播放器沿用源平台权限，普通网页可能禁止 iframe。已知视频提供商使用固定官方播放器域名，普通网页保留更严格沙箱；失败或限制时提供原链接。
- Mermaid 和 Excalidraw 按需加载；白板字体由 Fob 本站准备和提供。开发与构建入口执行 `scripts/prepare-rich-content.mjs`，不依赖外部字体 CDN。
- JSON 正文编辑器在 NodeView 刷新前记录即将提交的文档，忽略插入过程中的旧本机快照回声；外部同步不重复发布正文更新。双窗格编辑与连续属性更新均保留最新内容，已销毁的编辑器不再执行同步命令。

## 导入、导出与兼容

- 无损 Markdown 保留块身份和完整属性。Mermaid 与 PlantUML 分别使用标准 mermaid / plantuml 围栏，PlantUML 导入同时接受 puml 别名；白板使用 whiteboard directive，公共 Markdown 导出提供可重新导入的 excalidraw 围栏。
- 独立表情块使用 `emoji` 叶指令保存属性和身份；公共 Markdown 输出标准 Unicode，HTML 导出嵌入当前 OpenMoji 并移除编辑按钮。HTML 剪贴板保留 `data-emoji-value`；未知 Unicode 沿用文字回退，索引和 AI 描述读取同一持久值。
- PDF 在归档导出/导入中和原有媒体一样改写附件路径，回读恢复库内资产引用。
- 公共 Markdown 对链接卡片和外部嵌入保留来源，PDF 保留外部链接或库内附件名称；HTML 导出使用当前图表/白板预览、PDF 可见页面与原附件下载入口，外部 iframe 转为在线链接。资源不可读时沿用现有明确报错。

## 编辑器内容控件

- 图片、白板、Mermaid 与 PlantUML 的操作组共用“排布”菜单，使用与放大、替换一致的 1.75 线宽轮廓图标；靠左、居中、靠右选项不显示对勾，保留单选 ARIA 状态，以共享 schema 的 `align` 属性保存，支持协作、撤销及无损 Markdown／HTML 往返。旧图片默认居中，旧图形默认靠左，不在读取时改写已有正文。只读隐藏排布入口，提交操作时再次检查编辑权限；排布不改变资源、源码、块 ID、标题或说明。
- 图片复用图形边缘缩放交互，支持横向边缘、底边和下角拖拽，保持原始宽高比例；居中时按中心锚定，靠右时把横向及下角命中区放到左侧。初始保持固有尺寸、最多 640px 高并受正文宽度约束，手动尺寸以正文宽度的 1–100% 保存为 `width`／`autoWidth`，最小可操作宽度为 40px（正文更窄时优先适配）。拖动只预览本地样式，释放时一次写入；支持撤销、Escape、指针取消、丢失捕获、资源／排布／远端尺寸变化及撤权取消，双击边缘或按 Home 恢复自然尺寸，方向键调整。图片资源、说明和块身份保持不变。
- 内容块的附加操作复用 `block-modules/block-actions`：通常位于块外侧右上角，悬停、键盘聚焦或菜单展开时显示，触屏常显；图片、Mermaid 与白板使用 `placement="canvas"` 和 `touchVisibility="on-demand"`，在块内右上角按需淡入，不做位移或缩放。图片工具条相对于整个内容块定位，距上、右边缘各 8px，提供“放大”和“替换”：放大使用 Lucide 放大镜图标，图片直接悬浮于深色全视口遮罩，没有白色卡片、外框、阴影或可见标题行；关闭按钮固定右上角，缩放操作组悬浮底部中央。预览复用图形预览的缩放、平移、适配、键盘和关闭回焦，点击图片以外的空白关闭，拖拽结束不误关。替换复用媒体上传流程，更新当前块的资源，保留块 ID 与说明文字，取消选择不修改内容。只读仅提供放大，文件选择期间撤权后拒绝替换；隐藏页签不展示预览弹窗。代码块使用 `placement="inside"` 并保持常驻，复制与编辑者的更多按钮留在块内头部右侧，沿用代码主题材质。其他外置工具栏维持原有单层描边和 180ms 轻微缩放/上移弹出，减少动态效果偏好下直接显示；与内容间的 6px 间隙属于同一命中区域，全屏时移入视口内。
- 代码块头部的按钮与语言入口在悬停、按下和展开时均通过共享 `--action-state-ink` 保留当前代码主题文字色，浮层菜单使用系统主题；主题与语言菜单的选中标记使用统一的 18px `SelectionCheck`。
- 普通附件使用紧凑的单行细边框卡片：扩展名色块、文件名和实际大小，整卡提供下载入口，右上方工具栏提供打开与更换；两者使用同色、同尺寸的 Lucide 外链与双向箭头图标。PDF 保留阅读器。本机读取 IndexedDB，团队上传沿用哈希、授权直传、确认和签名下载流程。正文协作保存默认防抖 2 秒、最长 10 秒，新媒体引用可能先于持久化正文到达读取端。签名下载遇到短暂拒绝、未就绪或网络错误时，按 250／500／1000／2000／4000／4000ms 有限重试，每次仍由服务端验证实际正文引用和 ACL；未认证与输入错误立即失败。加载期间保留加载状态，持续失败显示原错误，“重试”重新读取当前媒体，不打开文件选择器。切换资源、手动重试和卸载会取消旧请求及定时器。本机 IndexedDB 与外部 URL 路径保留。从文件选择窗口回到页面会触发会话刷新；相同用户的新对象不能重建 Tiptap。扩展装配只依赖用户 ID、姓名和归一化头像等实际字段，保持选图回调与进行中的上传所绑定的编辑器实例。文件选中时再次检查可编辑权限，实际资源／主体切换仍遵循会话生命周期。媒体节点可保存可空的非负整数字节数 `size`，兼容旧节点；团队下载授权不包含元数据时，使用上传时写入的大小，无已知大小时保留真实 MIME 或附件标签。
- 提示框使用浅色语义底、细边框和同色正文；文字继承当前正文的字体、字号和行高，内边距为 8px/12px。左侧使用 [默认 OpenMoji 表情集](ui/emoji-system.md)，弹层仅包含表情搜索和分类；右上方使用独立的 168px 类型菜单，普通、提示、成功、警告、错误及自定义各有相应语义图标，自定义使用炫彩调色板。切换类型只改变语气和背景，保留所选表情。自定义背景复用 248px 颜色面板，支持色相、饱和度、透明度和十六进制输入，以校验后的六或八位十六进制 `background` 属性保存，切回预设时清空；文字按背景亮度保持对比。弹层复用共享定位、视口避让、Escape 与回焦逻辑，只读不显示编辑入口。
- 表格整表操作统一进入左侧六点块菜单；原列、行和单元格菜单保留 13px 字号、28px 行高、182px 宽度，自定义颜色面板仍为 248px。移除左上圆球和整条行列轨道，当前行列边缘显示 12px 短把手，24px 点击区悬停展开为更多按钮，仍支持拖动重排。底部与右侧使用 16px 浅灰圆角添加条，距表格 5px，复用共享 Tooltip：点击添加一行或一列，向外拖动预览并批量添加，单次最多 100 项、一次撤销；Escape、指针取消、失焦、只读和并发修改不写入预览内容。控件不进入正文或导出。单元格、行列和矩形选区使用单层 2px 蓝色外框，不额外叠加选中背景，保留表头和内容原有颜色；横向滚动时按可见表格边界裁切外框。 单元格选区工具栏直接组合正文选区工具栏的共享 CSS：27px 按钮、H1–H3 文字、分组分隔线、8px 圆角、描边、阴影与按下反馈一致；链接和评论共用同一图标。保留合并、拆分与单元格背景操作，移除旧三角箭头；工具栏使用与正文一致的浮层宿主，按编辑区域和评论边界避让，在选区上方放不下时置于下方；窄屏单行横向滚动，不将分组折成多排或被编辑器滚动容器裁切。
- 文档星标工具仅在悬停或键盘聚焦时显示共享中性背景，选中后不保留底色；保留实心金色与按下语义。正文目录入口统一为左侧短线轨道，顶栏不再重复展示目录图标；章节折叠与悬浮目录见 [标题章节导航](editor-heading-navigation.md)。分享入口带左侧图标与加粗文字，选区评论与回复使用统一的 `ChatCircleDots`。
- 文档标题在 48px 顶栏下方保留 16px 顶部间距。顶栏覆盖阅读滚动区域，不添加底部分割线；支持 backdrop-filter 时使用跟随深浅主题的 76.6% 面板底色与 26px 模糊（相比初版，模糊半径与背景透出比例均增加 30%），否则保留实色底。正文标题完全滚入顶栏后，当前文档名在顶栏几何中心以 200ms 淡入与 240ms、6px 上移动效显示；回顶反向隐藏。两侧控件通过 ResizeObserver 测量，按较宽一侧加 12px 预留对称空间，长标题截断，剩余宽度不足 80px 时隐藏顶栏标题以保留操作。滚动监听复用目录的被动监听与逐帧调度，仅在状态切换时修改 DOM 属性；不按滚动帧重渲染正文。监听在编辑器初始化前绑定，初始化事件、恢复滚动位置和布局变化会重新核对状态。目录跳转及浏览器定位为覆盖式顶栏预留空间，文件预览保留原顶栏占位；减少动态效果偏好下直接切换。
- 选中文字的高亮按钮点击切换高亮：选中时取消，未选中时应用本次使用的颜色（初始为浅黄）。悬停或按方向下键打开两行四列的颜色菜单，七种浅彩色预设与第二行最后一格自定义入口；取消动作只保留在高亮图标，不另设菜单项。自定义复用现有颜色面板，支持色相、饱和度、亮度、透明度和十六进制输入，点击应用后一次写入选区，关闭不应用草稿。二级浮层保持原选区，支持键盘进入、Tab 到应用、Escape 与外点关闭。颜色保存在共享 `highlight.color`，按安全十六进制输出背景；正文、协作、撤销、HTML 复制与无损 Markdown 使用同一属性，旧高亮值仍可读取和修改。
