# 编辑器富内容块

## 范围

支持独立表情、链接卡片、Mermaid 图表、PDF 内嵌预览、B站视频及 Excalidraw 白板。Figma 等其他平台后续按实际使用需求扩展。全部节点由 `shared` 注册语义，浏览器模块仅负责交互与呈现，沿用稳定块 ID、Yjs、撤销、模板和知识库权限。

| 内容 | 权威数据 | 插入与编辑 |
| --- | --- | --- |
| 表情 | Unicode `value` | `/表情` 或 `/emoji` 插入默认 😀；点击更换，复用 448 个本地 OpenMoji 与搜索、分类、键盘操作；只读仅展示 |
| 链接卡片 | 原链接、标题、摘要、封面地址、来源名称 | `/链接卡片` 或空段落粘贴独立 URL；可转换为普通链接或嵌入，并手动编辑资料 |
| Mermaid | 源码、标题、宽度比例、高度 | `/mermaid` 或 Markdown mermaid 围栏；完整等比预览、常驻原地编辑标题、块内按需操作组和自然边缘缩放 |
| PDF | 库内附件引用或外部 URL、标题、说明、高度 | `/pdf` 上传或填写链接；既有 PDF 附件也使用阅读器；支持翻页、缩放、下载和全屏 |
| B站 | 原链接、标题、高度 | `/B站` 或网页嵌入；识别 BV、av、官方播放器链接，保留分P与起播秒数，关闭自动播放 |
| 白板 | Excalidraw 场景、PNG 预览快照、标题、宽度比例、高度 | `/excalidraw`；正文完整等比预览、常驻原地编辑标题、块内按需操作与自然边缘缩放、模态画布明确保存/取消、源文件下载 |

## 数据、权限与外部依赖

- PDF 复用本机 IndexedDB 和服务端授权上传、签名下载，不另建公开附件路径。外部 PDF 依赖源站 CORS 与访问权限，失败保留原文件入口。
- 白板场景属于页面正文，包含图元和必要图片，不保存协作者、选中状态等运行时信息。首版限制 2000 个图元及 4 MiB，图片支持 PNG/JPEG/GIF/WebP；外部网页使用独立嵌入块。编辑会话打开后若场景被其他客户端修改，拒绝覆盖并提示重新打开。
- 白板保存时同时生成最长边 1024px 的 PNG 预览和场景 SHA-256，随页面权限持久化；普通阅读直接显示匹配的快照，源数据被外部修改、旧场景或损坏快照回退到场景渲染。预览只接受有界的 PNG data URL。
- Mermaid 与白板保留统一的 1px 浅色细边框、8px 圆角和 16px 预览留白。左上角常驻轻量标题，与图形之间不加分隔线或底色。标题靠上排列，点击后直接在同尺寸的纯文字区域编辑，不显示输入框或描边，不占满剩余整行；回车或失焦提交，Escape 取消，外部重命名与撤权丢弃旧草稿。纯文本粘贴合并换行，限制 500 字符，中文输入法确认不触发提前提交。空标题回退到内容类型，只读显示纯文字标题。HTML 与公共 Markdown 导出保留标题。
- 操作组在块内右上角，使用 3px 内边距、2px 间距、独立 6px 按钮圆角和单层浅色描边，只保留编辑、下载与全屏等操作。悬停、点击块或键盘聚焦后显示，失焦并移开后隐藏；触屏通过点击唤出，工具按钮至少 44px。窄块的标题与操作组自动分行，避免标题被挤掉。全屏适配可视区并保留退出入口。
- 两种图形块通过隐形边缘区域自然缩放：右边只改宽度，底边只改高度，右下角同时改宽高；各自支持对应方向键。桌面边缘命中区 10px、右下角 20px，沿外框向外延伸 3px，角区优先且与边缘区域衔接；触屏分别为 16px、32px。只切换方向指针，默认、悬停、聚焦和拖动均不绘制额外手柄、图标、反馈线或边条；复用共享缩放控件的 `data-resize-feedback="cursor"` 模式。拖拽仅预览受影响方向的尺寸，松开后一次写入正文，可一次撤销；Escape、指针取消、丢失捕获、远端尺寸变化或撤权恢复当前已保存尺寸。宽度保存为文档宽度的 25–100%，高度为整个块的 200–1200px；最小可操作宽度 280px，正文更窄时适配正文。完整图形在剩余空间等比适配，不产生内部滚动。只读和全屏不提供尺寸编辑。
- Mermaid 通过“编辑图表”进入源码模式，保留源码即时保存行为；点击“预览”回到完整图表。两种块订阅编辑权限变化，转为只读时关闭标题、源码与尺寸编辑，保留预览、下载及全屏等阅读操作。
- 白板编辑弹窗仍支持标题，与场景和预览一起显式保存；取消保留原标题和绘图，关闭或销毁后的异步保存不得回写。打开会话后若场景或标题被其他客户端修改，拒绝覆盖并提示重新打开。
- 网页摘要由 Fob 业务服务抓取公开 HTML；`knowledgeBaseId` 与 `source` 明确作用域。服务端库请求校验知识库身份，本机库可匿名获取公开网络资料，接口不查询任何 Fob 文档或资产。只信任 Fob origin，限制速率、并发、超时、重定向和响应大小；每跳检查并固定公网 DNS 地址，不发送源站 Cookie 或执行脚本。
- 卡片元数据保存为正文快照，仅编辑者在插入或重试时获取；只读打开不触发摘要抓取。源站失败支持重试和手动填写，不虚构网页信息。
- 外部播放器沿用源平台权限，普通网页可能禁止 iframe。已知视频提供商使用固定官方播放器域名，普通网页保留更严格沙箱；失败或限制时提供原链接。
- Mermaid 和 Excalidraw 按需加载；白板字体由 Fob 本站准备和提供。开发与构建入口执行 `scripts/prepare-rich-content.mjs`，不依赖外部字体 CDN。
- JSON 正文编辑器在 NodeView 刷新前记录即将提交的文档，忽略插入过程中的旧本机快照回声；外部同步不重复发布正文更新。双窗格编辑与连续属性更新均保留最新内容，已销毁的编辑器不再执行同步命令。

## 导入、导出与兼容

- 无损 Markdown 保留块身份和完整属性。Mermaid 使用标准 mermaid 围栏；白板使用 whiteboard directive，公共 Markdown 导出提供可重新导入的 excalidraw 围栏。
- 独立表情块使用 `emoji` 叶指令保存属性和身份；公共 Markdown 输出标准 Unicode，HTML 导出嵌入当前 OpenMoji 并移除编辑按钮。HTML 剪贴板保留 `data-emoji-value`；未知 Unicode 沿用文字回退，索引和 AI 描述读取同一持久值。
- PDF 在归档导出/导入中和原有媒体一样改写附件路径，回读恢复库内资产引用。
- 公共 Markdown 对链接卡片和外部嵌入保留来源，PDF 保留外部链接或库内附件名称；HTML 导出使用当前图表/白板预览、PDF 可见页面与原附件下载入口，外部 iframe 转为在线链接。资源不可读时沿用现有明确报错。

## 编辑器内容控件

- 内容块的附加操作复用 `block-modules/block-actions`：通常位于块外侧右上角，悬停、键盘聚焦或菜单展开时显示，触屏常显；Mermaid 与白板使用 `placement="canvas"` 和 `touchVisibility="on-demand"`，在块内标题右侧淡入，不做位移或缩放。代码块使用 `placement="inside"` 并保持常驻，复制与编辑者的更多按钮留在块内头部右侧，沿用代码主题材质。其他外置工具栏维持原有单层描边和 180ms 轻微缩放/上移弹出，减少动态效果偏好下直接显示；与内容间的 6px 间隙属于同一命中区域，全屏时移入视口内。
- 代码块头部的按钮与语言入口在悬停、按下和展开时均通过共享 `--action-state-ink` 保留当前代码主题文字色，浮层菜单使用系统主题；主题与语言菜单的选中标记使用统一的 18px `SelectionCheck`。
- 普通附件使用紧凑的单行细边框卡片：扩展名色块、文件名和实际大小，整卡提供下载入口，右上方工具栏提供打开与更换；两者使用同色、同尺寸的 Lucide 外链与双向箭头图标。PDF 保留阅读器。本机读取 IndexedDB，团队上传沿用哈希、授权直传、确认和签名下载流程。媒体节点可保存可空的非负整数字节数 `size`，兼容旧节点；团队下载授权不包含元数据时，使用上传时写入的大小，无已知大小时保留真实 MIME 或附件标签。
- 提示框使用浅色语义底、细边框和同色正文；文字继承当前正文的字体、字号和行高，内边距为 8px/12px。左侧使用 [默认 OpenMoji 表情集](ui/emoji-system.md)，弹层仅包含表情搜索和分类；右上方使用独立的 168px 类型菜单，普通、提示、成功、警告、错误及自定义各有相应语义图标，自定义使用炫彩调色板。切换类型只改变语气和背景，保留所选表情。自定义背景复用 248px 颜色面板，支持色相、饱和度、透明度和十六进制输入，以校验后的六或八位十六进制 `background` 属性保存，切回预设时清空；文字按背景亮度保持对比。弹层复用共享定位、视口避让、Escape 与回焦逻辑，只读不显示编辑入口。
- 表格主菜单与二级菜单统一 13px 字号、28px 行高，主菜单宽 182px，自定义颜色面板宽 248px；行列控制条厚度为 10px。
- 目录空态只显示“暂无章节”；折叠图标与章节标题是同级按钮，图标改变展开状态，标题始终定位章节。分享入口带左侧图标与加粗文字，选区评论与回复使用统一的 `ChatCircleDots`。
- 选中文字的高亮按钮点击切换高亮：选中时取消，未选中时应用本次使用的颜色（初始为浅黄）。悬停或按方向下键打开两行四列的颜色菜单，七种浅彩色预设与第二行最后一格自定义入口；取消动作只保留在高亮图标，不另设菜单项。自定义复用现有颜色面板，支持色相、饱和度、亮度、透明度和十六进制输入，点击应用后一次写入选区，关闭不应用草稿。二级浮层保持原选区，支持键盘进入、Tab 到应用、Escape 与外点关闭。颜色保存在共享 `highlight.color`，按安全十六进制输出背景；正文、协作、撤销、HTML 复制与无损 Markdown 使用同一属性，旧高亮值仍可读取和修改。

手柄避让与虚影保持见 [文档块拖拽](editor-block-drag.md)，本轮界面验证见 [.spec/tasks/editor-polish.md](../.spec/tasks/editor-polish.md)。
