# 知识发现与文件夹首页

Fob 以知识库为唯一工作空间与权限边界。文件夹对应当前知识库的 teamspace；检索、目录、概览、置顶和管理操作均携带 `knowledgeBaseId`，不借用 Outline 的账号、数据库或浏览器状态。

## 工作台与导航

横向分栏时，右侧页面的页签位于右栏上方，和栏内容保持 12px 的左内边距。系统栏与正文使用同一个拆分比例；拖动、键盘调整、侧栏宽度变化时一起更新。小于 640px 的内容区域沿用纵向分栏和统一页签列。页面宿主与协作编辑器保持挂载，拆分和调整宽度不重建正文实例。

当其中一栏不足以容纳页签与系统操作时，历史导航和系统操作移到上行，两栏页签留在各自下行；所有入口保持可用，单个页签随可用宽度收缩。

文件夹名称打开文件夹首页，独立的折叠箭头控制资源树。文件夹路由使用 `?knowledgeBase=…&source=server|local&folder=…`，保留当前工作页签；文档和文件夹目标互斥。文件夹名称同步为工作页签标题，目录分页持续加载，超出首批的文件夹仍可进入。成员看不到的目标呈现错误和重试入口。

## 文档集合页面

星标、草稿和回收站共用 `DocumentCollectionPage`，团队库与本机库仅在资源适配器中提供真实记录、文件夹和操作。页头只保留页面图标、标题、真实数量与可用的新建入口，移除重复的知识库小字。默认使用文档卡片，以正文预览、标题、所在位置、作者及日期形成清晰层次；也可通过共享 `ViewSwitcher` 切换为紧凑列表。材质沿用共享资源卡片的单层描边和中性色，不增加浮动阴影或位移动效。

工具区统一提供位置筛选、标题/文件夹路径/作者搜索、时间或标题排序和视图切换；条件与滚动归属当前知识库和页面会话。每次显示 24 篇，可继续加载。空集合、搜索无结果、加载和错误均保留各自的共享反馈与恢复入口。星标和草稿提供快速移出及原文档菜单；回收站保留恢复操作，不打开或读取已删除文档正文。团队库显示删除时间，本机库未记录删除时间时明确显示更新时间。本机永久删除先确认，并重验同库、同文档且仍在回收站。

正文摘要使用共享纯函数提取真实标题、段落和列表文本，不生成填充文案，不将代码或图表源代码当作正文。已有白板可使用其已保存的 PNG 缩略图；只允许受限大小的 PNG data URL，不抓取外部封面或媒体。没有正文、纯图表/附件和预览不可用分别展示真实状态。

团队库由适配器按当前可见卡片分批调用只读 `POST discovery/previews`，每批最多 24 篇，以当前主体和知识库隔离缓存并支持请求取消。服务端刷新 read 凭据后应用当前页面 ACL 和未删除条件，只对可见页面解码权威正文；未知、外库和无权页面不返回任何摘要。单篇超过 4 MiB 或无法解码时返回预览不可用，Y.Doc 状态和图表源数据不出服务端。本机库直接从当前库正文生成同样的摘要，不上传内容。

窄屏依次收为双列、单列卡片，工具区换行，列表日期转到文档信息下方；深色主题复用既有令牌。本机存储限制保留在内容下方。模板与文件夹列表也移除重复知识库小字，保留各自页面结构和操作。

## 导入与文件夹层级

编辑器“更多 → 导入”将内容插入当前文档选区；没有选中文本时插入光标位置，保留文档身份、标题与其他已有内容，不创建页面或切换路由。Markdown 和 TXT / TEXT / LOG 复用共享正文解析器、块身份和编辑器呈现；PDF、图片及其他支持的文件通过现有资产管线插入对应正文块。每次选择作为一个编辑器事务写入，文件读取完成时重验编辑权限，切换或关闭文档后取消写入。无效文件或超限文本不写入任何部分。

文件夹在侧栏、文件夹卡片及首页“更多”中提供导入和创建子文件夹。文件夹导入按所选文件分别新建文档；文本保存为原生编辑器正文，不上传为独立的文本预览文件。移除旧 Markdown / TXT 文件预览渲染和将文本关联为预览文件的入口，不为废弃文件记录增加转换或回填逻辑。

文件夹可以多层嵌套，资源树和文件夹首页展示真实父子关系；本机库导航或刷新打开深层目标时展开其祖先，用户随后仍可手动折叠。服务端以同一知识库内的 `teamspace.parent_id` 复合外键保存层级，本机库在同一知识库的文件夹记录中保存父 ID。创建和移动均校验目标存在且属于当前知识库；含子文件夹的文件夹不可直接删除。层级不额外授予权限，每个文件夹继续使用既有权限边界；服务端子文件夹创建表单初始采用父文件夹的默认成员权限，后续可独立管理。目录数据、列表和导入始终以 `knowledgeBaseId` 为作用域。

侧栏文件夹行支持原生拖放：拖到其他文件夹行成为其子文件夹，拖到“文件夹”分区标题区恢复一级。拖动期间标题区显示对应提示并作为明确落点，保持目录行位置不变；有效目标显示共享中性反馈和 1px 拖拽描边，停留 600ms 展开目标。文档行可拖到任意层级的文件夹，也可将同文件夹的子文档提升为根文档。自身、后代、原位置、删除目标及文档的无文件夹落点被拒绝，行内菜单与展开按钮不启动拖拽。快速拖入同时处理 dragenter，避免释放时尚未触发 dragover 而漏掉最终目标。

文件夹移动使用独立的 `POST /api/knowledge-bases/:knowledgeBaseId/teamspaces/:teamspaceId/move`，显式传入 `parentId`（一级为 null），仅 owner/admin 可操作。在知识库写锁中锁定源和目标，重验活跃凭据并递归检查祖先；对向并发移动无法形成环。移动保留完整子树、文档、metadata 和每个文件夹的独立权限。文档跨文件夹拖放复用 `page.transfer` 的源 full、目标 edit 与权限继承重建；同文件夹提升复用 `page.move`。服务端成功后刷新同库目录和页面查询，本机以一次 scoped store 更新保存；失败保留原位置，批次请求期间阻止重复移动。

刷新打开本机文档或文件夹时，入站目标保留到身份会话检查完成，避免临时访客范围提前消费地址后又恢复账号的上次团队库；手动切换知识库继续清除旧目标。

现有数据库通过 `bun --env-file=.env.fob.local backend/server/scripts/upgrade-folder-hierarchy.ts` 增量增加父级列、约束与索引；初始化快照使用相同结构。升级保留文档和已有文件夹。

## 搜索

系统搜索提供标题与正文关键词检索、单选文件夹和单选作者，两个条件取交集。条件为空时展示最近更新，允许只选择筛选条件。作者来自当前主体可查看的文档创建者；回收站、其他知识库及无查看权限的页面不进入结果。

服务端在标题查询和 PostgreSQL BM25 召回的排序、截断前同时应用文件夹、作者与页面 ACL；随后重新检查可见性并合并文档。一次展示最多 40 篇，达到召回窗口时提示缩小范围。正文命中保留真实 blockId，打开后使用已有文档定位通道。180ms 防抖、请求取消、主体与知识库隔离的查询缓存避免旧结果串入新范围。

本机库在当前库的真实文档上执行同样的过滤，未知作者显示“当前设备”。空关键词按更新时间排序，正文片段只在实际命中时显示。↑↓、回车、Escape 支持文档选择与打开，筛选器支持输入查找及方向键选择；关闭后回到原焦点。加载、无结果、权限和网络错误分别呈现。

## 文件夹首页

| 页签 | 数据与排序 |
| --- | --- |
| 概览 | 仅展示文件夹的富文本正文，直接使用完整文档编辑器内联编辑和自动保存 |
| 文档 | 置顶文档优先，随后为未置顶根文档；每组保留目录顺序，也可保存标题、更新时间或创建时间的升降序 |
| 热门 | 全部可见文档，按真实成员阅读次数降序 |
| 最近更新 | 正文状态与元数据的最近时间降序 |
| 最近最少更新 | 正文状态与元数据的最近时间升序 |
| A–Z | 标题顺序，服务端以确定性规则分页 |

文件夹仅保留六个页签，不定义“最近发布”或以创建时间冒充发布时间。旧的发布页签状态回退到“文档”，后端拒绝该排序值。旧文档未记录创建时间时保留未知状态，不推算日期。本机热门显示设备阅读，和团队成员阅读分开标识。正文与元数据更新才改变更新时间，单纯阅读不改变时间排序。

服务端列表每批 40 篇，稳定次序以页面 ID 消除同值歧义，返回的数量与置顶内容均经过 ACL。文件夹搜索匹配标题。新建、导入、文档菜单复用已有真实流程；文件夹菜单提供简介、重命名、默认成员权限和订阅，资源树保留已有重命名、星标、标签和删除能力。

同一文件夹切换页签或搜索时保留页头、工具区和页签 DOM，仅以 `aria-busy` 更新列表；查询占位只可复用相同知识库、文件夹、主体的数据。切换文件夹重新恢复对应的页签状态，不沿用上一文件夹的搜索。文档排序入口位于文档页签旁，更多菜单仅保留操作。默认权限复用组织界面的 `PermissionSelect`，菜单在模态层内展开，选中值只有点击保存后才写入。

文件夹页签共用一个 3px 下划线，点击或键盘切换时以弹簧动画滑至当前标签并匹配文字宽度；每个文件夹视图独立标识，横向滚动后仍跟随选中项，遵循系统减少动态效果偏好。概览沿用文档的共享任务列表样式，复选框和勾选标记按首行实际行高居中，换行或嵌套内容不将标记拉到整项中部。

概览正文在页签区原有间距之外增加 8px 顶部内边距；文档等列表页签不增加此间距。

文档页的置顶优先在服务端分页之前完成，置顶的子文档也会进入顶部；搜索仍过滤全部结果，其他页签维持各自排名。本机文档使用同一分组显示规则。置顶按钮以图标深浅和 ARIA 按下语义表达状态，常态、悬停及选中均不加背景色，窄屏也可操作；单篇与批量置顶不展示 loading 或瞬时禁用，操作层阻止请求期间重复提交，失败保留原状态并显示真实错误。取消置顶后恢复当前排序位置。

管理员可维护概览、图标、置顶和排序。概览与本机文档共用 `useStandaloneEditor`，与协作文档共用 `DocumentEditorContent`、同一 schema、块模块、斜杠菜单和选区工具栏；只由适配器区分持久化，不再维护独立编辑器或编辑弹窗。概览不展示文档、置顶、最新列表，也不展示新建文档空状态。

`teamspace.metadata` 保存概览等属性和递增 revision；正文 600ms 防抖自动保存，请求串行提交并合并写入期间的新编辑，离开视图时提交尾部更改。失败保留当前正文与当前账号、知识库、文件夹隔离的恢复草稿，显示错误和重试入口；冲突不会自动覆盖远端内容。写操作先锁定权限边界及文件夹，再校验 expectedRevision，拒绝跨文件夹置顶和过期版本。默认权限使用既有组织 API 与权限重建路径；本机变更通过当前库的持久化存储完成，失败会明确提示。

等待资源锁的写请求会重新校验活跃会话或令牌、读写范围及最新管理员身份。原目录重命名与权限修改也推进 metadata revision。失去查看权限的置顶文档既不进入列表，也不通过 metadata 暴露页面 ID。

## 视觉约定

文件夹首页按用户提供的 Outline 原图与本地运行源码还原：内容宽度 832px，标题 36px/45px、600 字重，页签 14px/21px 与 3px 下划线，文档标题 18px、辅助信息 13px，使用原版蓝灰文字与无分隔线的列表节奏。文件夹图标在标题左侧独立对齐；勾选时使用 18px 原版蓝色复选框和底部浮动批量工具栏。用户已选的图标、文档名称和真实统计继续展示。

按后续反馈，自定义文件夹图标采用 32px，目录图标采用 12px，使用同一个持久化值；再次选择当前图标或点击移除可清空并恢复默认图标。目录 API 仅增加图标字段，不外传概览正文或置顶元数据。收藏与侧栏共用 `--knowledge-star-color` 黄色。文件夹顶栏操作简写为“新建”和“导入”；新建使用实际 18px 的加号，导入保留上传图标及与新建一致的描边按钮容器。

用户指定的原版图标作为局部视觉参考例外，集中于图标目录，保留官方 BSD 许可、来源和资源摘要；不替换系统导航图标。现有编辑器、菜单、Toast、模态与搜索仍复用 Fob 公共组件。六个页签是用户明确要求的产品差异。窄栏页签和批量工具栏支持横向滚动，操作区换行；深色主题提供对应的可读颜色。

批量操作接入真实星标、文件夹置顶、移动、个人草稿和回收站。跨文件夹转移使用独立的 `page.transfer`，保留原 `page.move` 的同文件夹排序约束；要求源文档 full 权限、目标文件夹 edit 权限及有效写凭据。在同一知识库锁和事务中更新子树位置、保持页面 ID 与正文/历史/显式 ACL，并重建目标继承权限。数据库行须随所属数据库一起移动。回收站操作保留恢复能力，后台刷新不会改变确认弹窗中的目标集合。

## 数据库升级

新库由当前 schema 创建。既有 Fob 数据库运行一次非破坏升级：

```powershell
bun --env-file=.env.fob.local backend/server/scripts/upgrade-discovery.ts
```

该脚本只增加 `resources.teamspace.metadata`，保留现有文档与权限。验证记录见 `.spec/tasks/knowledge-discovery.md`。

功能与视觉参考本地 Outline `f4e87b3` 的 Collection；搜索保留 Fob 原有设计。延迟加载已核对仓库安装的 Next.js 16 指南，验证证据见 `.spec/tasks/knowledge-discovery.md` 与 `design-qa.md`。
