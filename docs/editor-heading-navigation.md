# 标题章节折叠与悬浮目录

## 章节边界与状态

正文中有后续内容的标题左侧显示统一的折线箭头。点击后收起同一父容器内、直到下一个同级或更高级标题之前的内容；末尾章节延伸到容器结尾。子章节可单独折叠，父章节展开后保留子章节状态。嵌套引用、提示框中的标题只管理自己的兄弟内容。

折叠属于个人阅读状态，使用页面会话命名空间中的稳定 `blockId` 保存；不改正文、共享属性、撤销栈、服务端权限或协作数据。插入和重排保留状态，删除标题清除失效状态。折叠包含当前光标时，将光标移回标题末尾。显式选择隐藏内容时自动展开祖先章节。

`extensions/heading-sections.ts` 计算章节边界并通过 ProseMirror 节点装饰隐藏整个内容块，包含列表、表格和富内容 NodeView；选区变化复用边界缓存。`components/heading-sections` 在编辑器外提供按钮，统一覆盖本地、服务端、只读与文件夹正文。标题拖拽按钮向外让出一个控件位置，不与折叠按钮重叠。

## 目录交互

正文左侧常驻短线导航轨道，常态所有短线为灰色，按实际标题层级使用 18px、12px、6px、最低 4px 的紧凑长度；当前阅读章节也不额外变长或变黑。鼠标进入或点击轨道后打开悬浮目录；离开轨道及浮层 180ms 后关闭。顶栏目录按钮可保持目录展开，再次点击关闭。

轨道始终透明，悬停、按下及展开均不显示整条背景面。指针沿轨道滑动时，以纵向位置形成连续的 Dock 式响应：最近短线变为 38px 深色线，邻近两侧短线按距离逐渐伸长、加深；目录条目的悬停与键盘焦点同步驱动该预览。预览不会滚动正文或改写当前阅读位置，离开后恢复所有短灰线。宽度以 160ms 平滑跟随，减少动态效果偏好下直接切换。逐帧更新只作用于短线层，不触发正文重渲染。

目录浮层宽 320px，18px 圆角，条目 32px 高、14px 常规字重，每层缩进 12px。标题级别跳跃按真实祖先层数缩进；不显示树形连接线、计数、折叠按钮或重复标题。文字默认灰色，当前位置为深色，悬停使用共享中性底色。长目录内部滚动，长标题截断并保留完整提示；浮层由共享 `AnchoredPopover` 避让视口边缘。

条目始终定位正文标题，定位隐藏章节前先展开其祖先；不会改变该章节自身的折叠状态。定位避让覆盖式顶栏，减少动态效果时直接滚动。键盘支持方向键、Home、End、Enter、Escape 与外点关闭。

## 定位与导出

目录、全文搜索及块链接共用 `expandHeadingSectionsAt` 展开目标祖先。当前章节计算忽略隐藏标题，保留原有文档标题滚动反馈。

HTML 导出同步展开所有章节、克隆并采集渲染样式，然后立即恢复原阅读状态；即使快照失败也恢复折叠。同步过程不跨绘制帧，不保存临时展开状态。导出包含完整正文，省略交互按钮。Markdown 等基于文档模型的输出天然保持完整。
