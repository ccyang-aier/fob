# 文档导入与移动

文档更多菜单统一提供导入和移动，本地知识库与服务端知识库分别使用自己的资源适配器。普通页面与文件页面共享入口；菜单不再将这两项显示为“待实现”。

## 文本导入

TXT、TEXT、LOG 和 Markdown 导入为 Fob 原生文档，与新建文档使用相同的标题、目录、正文编辑器、排版和协作流程。文件名移除对应文本扩展名后成为标题；文本类型不再仅凭标题扩展名判断。

- 纯文本按行转换为普通段落，保留空行、Unicode 和字面符号。Markdown 使用共享解析器转换为原生标题、段落、列表、格式和代码块。
- 新文档重建块身份，清除源评论、建议、数据库绑定和运行中 AI 身份。独立文本文件不能凭内部附件引用取得其他文档的附件访问权。
- 文本文件最大 1 MB。编码沿用 UTF-8、UTF-16 BOM 和 GB18030 解码；解析失败显示错误并允许重试，不创建空文档。
- 本机正文进入 `LocalDocument.body`，文本不建立文件预览关联。服务端 `page.importText` 在当前知识库事务内一次创建元数据、显式作者管理权限和权威 Y.Doc 正文，随后发布正常索引事件；重试同一页面 ID 不覆盖已有正文。
- PDF、Office、图片等非文本格式继续使用既有原文件上传与预览能力。

导入目标为当前文档所在文件夹，新文档独立于当前文档，原正文保持不变。目录、文件夹页及文档菜单共用相同导入器。

## 移动

移动弹窗列出当前知识库可访问的其他文件夹并支持搜索。服务端跨文件夹移动要求源页面完整管理权、目标文件夹编辑权及有效写入凭据，沿用 `page.transfer`；嵌套页面可通过 `page.move` 回到当前文件夹根级。本机页面还可移至未分类。

服务端移动保留页面与子页面身份、正文、附件和显式 ACL，重建目标继承权限并刷新目录与文件夹查询。本机更新只命中目标知识库的指定文档，保留正文、标签和其他库内容。请求期间阻止重复提交与关闭；失败保留所选位置，允许重试。

评论图标及右侧栏缩放分别遵循[图标系统](ui/icon-system.md)和[文档协作设计](document-collaboration.md)。执行门槛与证据见[任务记录](../.spec/tasks/document-management.md)。
