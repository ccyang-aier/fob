# FOA 推理团队汇报

打开 `index.html` 即可演示。共 7 页，16:9 画布，采用克莱因蓝瑞士风。字体、配图、动画、讲稿备注均包含在 HTML 中，可复制这一个文件离线使用。封面副标题为“业务、团队与运作规划”。

## 操作

| 操作 | 按键 |
| --- | --- |
| 前后翻页 | 左右方向键，也可滚轮或触屏滑动 |
| 首页与尾页 | Home / End |
| 页面总览 | Esc |
| 演讲者模式 | P，或右下角“演讲模式” |
| 静态模式 | B |

演讲者模式包含当前页、下一页、备注、计时和独立观众窗口。如浏览器提示，请允许打开观众窗口。总时长未指定，自动翻页默认关闭，可在演讲者设置中启用。

## 内容

1. 封面
2. 目录：业务、团队、运作
3. 业务定位与责任范围
4. 团队现状、能力与小组分工
5. 交付与质量管理
6. 能力与效率提升
7. 协同与团队氛围

人员经历和业务范围依据已确认大纲。PD 分离放在于心迪名下，APIKey 放在张婷婷名下。人力管道包含 PL，按非实习生成员每人 3 人月、实习生每人 1.5 人月，合计乘以 1.3 鼓包系数：总计 29.25 人月，小组一 13.65 人月，小组二 15.60 人月。

第 5 页直接展示例会制度（晨会、周例会）、Owner 机制、代码走读、版本问题单复盘，以及各自的执行动作和输出件。四个输出件区域目前标明材料名称，可替换为对应真实截图。第 7 页集中讲跨组协同、成员沟通和团队氛围。

## 来源与验证

基于 `../guizang/` 的瑞士风模板制作，保留原有演讲者运行时。上游许可证和字体署名包含在 HTML 内。

业务页三张配图通过 ImageGen 生成，源素材保存在 `images/`，并同时嵌入演示稿。核心特性使用细描边标签呈现。

已在 Chrome 中逐页检查，并验证翻页、总览、静态模式、备注保存、计时与排练、观众屏同步、圈选、屏幕控制和断开恢复。已检查 1600×900、1600×1000、1280×720 及移动屏幕比例，画布均保持 16:9。直接从本地文件打开时，字体与翻页正常，无外部网络请求。
