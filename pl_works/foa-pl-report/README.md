# FOA 推理团队汇报

打开 `index.html` 即可演示。共 7 页，16:9 画布，采用克莱因蓝瑞士风。字体、动画、讲稿备注均包含在 HTML 中，可复制这一个文件离线使用。

## 操作

| 操作 | 按键 |
| --- | --- |
| 前后翻页 | 左右方向键，也可滚轮或触屏滑动 |
| 首页与尾页 | Home / End |
| 页面总览 | Esc |
| 演讲者模式 | P，或右下角“演讲模式” |
| 静态模式 | B |

演讲者模式包含当前页、下一页、备注、计时和独立观众窗口。如浏览器提示，请允许打开观众窗口。总时长未指定，自动翻页默认关闭，可在演讲者设置中启用。

## 内容

1. 封面
2. 目录：业务、团队、运作
3. 业务定位与责任范围
4. 团队现状、能力与小组分工
5. 交付与质量管理
6. 能力与效率提升
7. 协同与团队氛围

人员经历和业务范围依据已确认大纲。小组职责为建议，PD 分离与 APIKey 的具体 Owner 待确认。

基于 `../guizang/` 的瑞士风模板制作，保留原有演讲者运行时。上游许可证和字体署名包含在 HTML 内。
