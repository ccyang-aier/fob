## 2026-11-05 成员操作坞与权限控件润色

当前设计仍由 `docs/ui/knowledge-base-members.md` 维护。本轮针对用户标注的四处问题调整现有成员页，不改业务 API、角色权限边界或已有授权含义。

- 选中成员后通过 Portal 在视口底部中央显示 44px 操作坞，表格上方不再插入批量操作行。成员表表头选中前后实测均为 y=225.333px；切到其他工作页时操作坞消失，返回保留选择。Escape 清除选择，打开的角色菜单优先处理 Escape；最后一位所有者仍不可选。
- 所有角色使用同样的 22px badge，普通成员为带细边界的中性灰徽标，选中行中仍可辨认。成员行调整为 56px、头像 30px；表头、搜索、计数和菜单间距统一。
- 单行与批量角色菜单共用 badge、简短能力说明和右侧 `SelectionCheck`；菜单选项与原有角色上限相同，未改变角色变更、移除确认、乐观更新和失败回滚。
- 权限、成员、文件夹选择统一使用现有 Radix 菜单，权限弹窗实测原生 `select` 数量为 0。成员与文件夹选择支持搜索；按 `viewer@` 筛选仅显示苏禾，选择后提交按钮才启用。授权列表显示头像、姓名、邮箱、数量和权限徽标，删除入口支持悬停、键盘和触屏。
- 键盘选择临时将当前用户的文件夹权限改为查看后取消，再次打开仍为可管理；取消未提交。随后原样保存当前配置，真实 API 成功、弹窗关闭并显示共享 Toast，原有授权含义保持一致。
- 使用当前 IAB 和当前 hahah 知识库六位真实成员验证；默认桌面 1074×871，窄屏覆盖 390×844，均检查真实页面而非静态 mock。390px 页面宽度与 scrollWidth 均为 390px，权限弹窗边界 x=16..374，操作坞 x=73.7..316.3、底边 y=764；只有数据表内部横滚。
