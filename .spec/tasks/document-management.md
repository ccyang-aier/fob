# 文档菜单与原生文本导入

当前设计：[文档导入与移动](../../docs/document-management.md)、[文档协作](../../docs/document-collaboration.md)与[图标系统](../../docs/ui/icon-system.md)。

## 实现

- [x] 选中文字的评论按钮使用其他评论入口相同的 `ChatCircleDots`，移除该入口的轮廓例外。
- [x] 评论和历史记录侧栏复用系统分隔手柄，支持反向拖拽、宽度限制、方向键及当前文档视图内的宽度恢复。
- [x] 文档菜单接通本机和服务端的导入、移动；文件页面同样可用，按实际权限启用，失败可重试。
- [x] TXT/TEXT/LOG 与 Markdown 作为原生正文导入，标题去除文本扩展名；普通段落及 Markdown 语义共用原生编辑器，不创建带行号的文件预览文档。
- [x] 服务端 `page.importText` 原子保存元数据、Y.Doc、作者 ACL 和索引事件；同 ID 重试保留已有正文。越权、跨库目标、只读凭据与不合法正文不能留下空文档。
- [x] 移动沿用现有树操作、目标授权与权限继承；本地操作仅更新当前库指定文档。

## 验收范围

本轮验证本机数据模型、服务端真实操作、桌面与窄屏内置浏览器流程。没有扩展 PDF/Office 等非文本格式的解析能力；此类文件继续使用已有预览和外部依赖。开发 CSS 热更新造成过一次暂时样式丢失，刷新后恢复；最终检查使用刷新后的稳定页面。
