# 主文档版本切换与左侧互动验收

设计：[文档协作、分享与洞察](../../docs/document-collaboration.md)。

## 用户要求与实现

- [x] 页面动态仅保留浏览记录、版本；移除编辑记录入口以及高亮、比较、保存版本、小预览等控件。
- [x] 点击版本直接在主文档区域显示该版本的标题与完整正文；当前版本、返回入口与关闭动态栏均切回实时文档。
- [x] 历史视图使用共享块渲染器和独立只读编辑器，不写入当前 Y.Doc；保留实时连接、权限、错误重试与作用域隔离。
- [x] 历史附件按当前页面 ACL 和仍保留的快照授权，撤权、删除快照后拒绝；不放宽私有页面或外部知识库边界。
- [x] 浏览记录用 24px 固定头像列、可截断姓名列、右对齐时间列，头像和文本行盒垂直居中。
- [x] 收藏旁增加点赞、送咖啡、评论；删除标题下方的旧评论入口，继续控制同一真实评论侧栏。
- [x] 点赞确认后回弹与粒子，送咖啡确认后举杯/蒸汽/飞杯，评论气泡弹跳；失败不伪造成功反馈，减少动态效果时关闭动效。
- [x] 送咖啡先选择数量，再确认赠给文档真实创建者；展示余额，禁止自赠、越权、透支、非法数量和切号后的错账户请求。
- [x] 转账同发送者跨知识库串行，数据库再次验证余额及来源；幂等请求不重复扣减，普通角色不能改写或删除已记账转账。
- [x] 签到与赠送共同汇总真实余额和账户账本；收赠和文档点赞同步至个人统计及对应勋章。删除原文档不改变已完成转账。

- 后端 80 项通过，1667 条断言，覆盖新旧数据库初始化、RLS、动态上限、点赞、数量赠送、跨知识库并发、幂等、余额与源页面删除、历史附件、当前权限、版本及正文持久化。
- 前端/共享契约 41 项通过，225 条断言，覆盖两页签、版本回调与错误恢复、移除旧控件、收藏共享反馈、菜单与奖励账户切换隔离。
- Web/server/shared 类型检查、全仓 lint、最终改动 ESLint、图标、中英文、架构和源码保留检查通过。
- `pnpm build` 通过，静态页生成 8/8；当前 SQL 与 Drizzle 一致。数据库增量升级后 ready，41 张表、36 张强制资源 RLS 表，无 schema 问题。
- 真实浏览器以两个独立测试账户验证初稿/定稿主文档切换、切回后的编辑能力、点赞刷新持久化和实际发表评论。确认只剩一个左侧评论按钮，编辑记录页签消失。
- 选择赠送 3 杯，发送者余额 6→3，接收者余额及收到咖啡均为 3；接收者真实收到文档点赞为 1。超过余额的数量不能提交，取消不扣款。

- 最终热更新稳定后的刷新采集到 0 条 console error，无框架错误覆盖层。热更新重启期间的短暂连接失败、首次懒加载的开发态警告未复现在最终检查。
