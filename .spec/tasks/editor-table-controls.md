# 表格操作入口与选区（2026-11-08）

当前设计：[富内容编辑器](../../docs/editor-rich-content.md)、[块菜单与拖拽](../../docs/editor-block-drag.md)。按用户参考图调整表格 block，不改变服务端契约或资源权限。

## 已实现

- 移除左上角整表圆球，整表操作进入左侧六点块菜单；表格激活时继续显示块入口。复用原整表菜单能力，支持 Markdown 复制；打开菜单不改变光标，执行动作时按稳定块 ID 重新定位。
- 行列整条轨道改为当前行列的边缘短把手，悬停显示更多按钮，保留点击菜单、拖动重排及原单元格右键逻辑。
- 底部和右侧使用窄圆角添加条与共享 Tooltip。点击添加一项，向外拖动预览数量后批量添加；一次最多 100 项，单个事务并隔离撤销批次，取消和陈旧目标不写入。
- 单元格、整行整列和矩形选择仅显示单层 2px 蓝色边框，无额外选中底色，保留原表头、内容背景；水平滚动裁切隐藏边界。操作层不参与正文和导出。

- 表格选区浮动工具栏复用正文选区共享样式与链接/评论图标；统一 H1–H3 文字、按钮、分隔线、圆角、阴影、按下反馈与窄屏滚动，保留表格专用动作；复用浮层宿主，按编辑区域/评论边界约束位置，选区上方不足时置于下方。

## 验证证据

- 83 项表格、块拖拽、块菜单和正文选区工具栏测试通过。覆盖合并单元格、原内容/块身份/邻块不变、标题、排序、格式、CSV、菜单目标、并发定位和只读，以及批量新增与单次撤销/重做。新增回归覆盖 Tiptap 复用事务的命令状态，避免向同一事务迭代追加步骤。
- Playwright 使用独立匿名本机知识库，1440×1000 与 390×844；页面身份和非空、无框架遮罩、最终控制台 0 错误/0 警告。当前会话没有 Browser 插件，使用 Playwright CLI；截图与临时脚本在仓库外。
- 真实 UI：Slash 插入表格；左侧整表菜单；原列排序菜单与单元格右键菜单；点击新增一行/列；拖动分别新增三行和三列；一次撤销仅移除本次新增并保留先前输入；Escape 取消不改正文；刷新保留数据；深色和窄屏横向滚动。
- 实际计算样式确认选区边框为 2px 蓝色、背景完全透明、所有 `.selectedCell::after` 为 `none`。视觉检查对照用户参考图，确认短把手、边缘添加条、原表头底色和单列外框。
