# Fob 侧栏与顶部工具入口

当前设计以[知识库与客户端架构](../../docs/architecture/fob-product-boundaries.md#知识库与客户端架构)及 [AI 前端规则](../../AI_FRONTEND_RULES.md)为准。

## 完成范围

- 展开侧栏依次显示设置、帮助、分隔线和底部签到卡片。收起时移除签到入口，帮助位于设置上方，设置固定为最后一个按钮，DOM 与键盘顺序一致。
- 签到卡片复用共享资源卡片，移除咖啡图标的底色容器，调整标题、说明、真实月进度与按钮的间距及对比度。
- 主题切换进入右上角工具组；咖啡位于通知右侧，使用单图标与中性色余额角标。无已确认数据时不显示数量，超过 99 杯显示 99+，完整余额保留在提示和可访问名称中。
- 文档工具栏移除所属文件夹入口及斜线，保留目录/缩略图、星标、分享、新建和更多操作；相应复制基线适配已按实际改动更新。

## 验证（2026-10-25）

- `pnpm typecheck`、改动 TSX 文件的 ESLint、`pnpm architecture:verify`、`pnpm i18n:verify` 均通过。
- 咖啡 API/Provider、主题切换、本地文档编辑实例相关回归：13 通过、0 失败、68 断言。测试环境有既存 KaTeX quirks-mode 提示，不是浏览器页面错误。
- 使用 Codex 内置浏览器的 Playwright 接口验证本机 3001 页面；在 1388×871 页面检查视觉适配，并在 1280×720 后台验证页完成交互检查，保留用户原页面的批注。
- 验证展开/收起、深色/浅色切换、咖啡余额进入详情、帮助弹窗、展开和收起状态下的设置入口，最后恢复浅色文档视图。
- DOM 检查确认收起侧栏无签到入口、设置为末项；文档工具栏无所属文件夹入口。卡片底部位于视口内，页面无横向溢出；深色角标为中性色，卡片图标无背景容器。
- 新加载的后台验证页内容完整，无框架错误覆盖层，控制台 0 错误、0 警告。批量 CSS 热更新时原页面曾出现一次 Turbopack 缺失样式 chunk 提示，刷新后恢复；未更改 Next.js 配置或启动模式。
- 截图仅保存在仓库外；本轮未进行移动端视口验证。业务服务和开发模式保持运行。
