# 评论与文字工具

当前设计：[文档协作](../../docs/document-collaboration.md)、[富内容编辑器](../../docs/editor-rich-content.md)、[导入与移动](../../docs/document-management.md)。

## 实现

- [x] 回复与选区评论统一 `ChatCircleDots`，共用输入器接入现有 448 个 OpenMoji，支持纯表情与光标处插入；阅读统一呈现，代码和未知表情保留字面内容。
- [x] 评论锚点改为浅彩色，计数高度随引用字号定位；保留问题、解决、孤立及临时状态。
- [x] 高亮支持悬停二级菜单；两行四列包含七种浅色与末格自定义，图标点击切换高亮并记住本次颜色，菜单不设移除项；不改变文本、块身份或评论绑定。
- [x] 团队导入区全区域可点选及拖放；文件输入与按钮互为同级，提示实际文件限制；弹窗底栏缩为 14px。
- [x] 核实当前各格式的处理方式，记录原生编辑与原稿预览的边界。未扩大 Office 转换范围。
- [x] 编辑器等本地缓存读取完成，未缓存正文等首次同步，避免打开和刷新时注入多余占位段落；不改写已有空段落。

## 边界

本轮扩展评论与选区工具，未扩展 Office/结构数据的原生转换。初始化等待阻止后续额外占位段落，不对既有正文的空段落做猜测性清理。开发期间发生过 CSS 热更新暂时丢失样式，刷新后恢复；截图与最终检查均使用稳定页面。
