## Escape 关闭

- 原星标和文档菜单测试手工安装的 DOM 构造器缺少 `HTMLInputElement`。共享菜单在 document capture 阶段执行搜索框 Escape 逻辑时引用该构造器，测试环境抛错，阻断 Radix 关闭；补齐后原星标两项回归立即通过。
- 引入测试专用 DOM 环境，统一构造器、绑定浏览器方法并在卸载后恢复全局；两组菜单测试使用该环境。星标场景逐项重新挂载，标题栏场景独立从未星标状态开始，Escape 增加关闭与延后回焦断言。
- 星标、文档菜单及基础下拉菜单共 11 tests / 85 assertions 通过，覆盖搜索清空优先于关闭、子菜单键盘进入、星标菜单保持展开、外观偏好及错误保留。
- 真实用户文档中打开“更多文档操作”→“复制”子菜单→Escape，关闭动画后菜单数为 0、入口 `aria-expanded=false`、焦点回到“更多文档操作”。未改变原星标或正文。截图 `menu-escape-closed.png` 位于仓库外 visualizations 目录。

## 性能

- 搜索插件分别缓存匹配结果和装饰。切换当前匹配只替换活动标记，选择变化直接复用状态与高亮；正文、查询和大小写变化重新匹配。导航工具按正文版本 / 查询缓存计数，关闭搜索后不扫描正文，也不为每次编辑额外派发同值搜索事务。
- 任务进度只在正文变化时通知，按不可变 ProseMirror 文档以 WeakMap 共享统计；重复视图、重复快照、模拟远端的正文事务和旧正文恢复保持计数正确，不无限保留正文。JSON 编辑器延后初始化同步记录，移除普通组件渲染时整篇 JSON 序列化；保留已有写回、快照回声与撤销规则。画布块不再安装不使用的浏览器全屏监听，其他卡片全屏保持原逻辑。
- 基于本轮改造前提交 `b9ef3cb` 的真实搜索插件和原任务统计闭包，以同样输入在 Node 诊断进程中对比：1000 段正文初始化搜索并导航 200 次，每次读取装饰 5 次，扫描从 201 次降为 1 次，1000 项匹配一致；该次耗时 4397.50ms → 28.64ms。1000 项任务读取 1000 次，扫描从 1000 次降为 1 次，已完成均为 500；该次耗时 118.78ms → 1.23ms。这是工作量诊断，不代表生产浏览器帧率或所有卡顿均已消除。
- 新增大文档结果导航 / 光标移动、正文 / 大小写失效、关闭搜索、嵌套任务、零计数缓存、双视图、模拟远端更新、旧正文恢复与编辑器移除回归；原有本机编辑同步、白板属性连续更新、尺寸 / 撤销与导出测试继续通过。
