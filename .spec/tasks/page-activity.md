# 页面动态验收

当前设计：[文档协作、分享与洞察](../../docs/document-collaboration.md#页面动态)。

## 实现范围

- [x] 文档更多菜单“历史记录”改为“动态”；按最新反馈仅保留浏览记录、版本两个页签，移除编辑记录入口。
- [x] 组件拆分为侧栏、浏览列表、版本列表和主文档历史视图；统一头像列、姓名列和时间列。
- [x] 浏览记录最多二十位不同账户，重复访问刷新最近时间；编辑记录最多二十次已提交编辑；版本最多十五个完整快照。
- [x] 数据库触发器在写入事务中物理清理超额行，按知识库/页面隔离并串行处理并发；新库初始化及存量增量升级均安装规则。
- [x] 编辑记录与正文事件、outbox 和任务调度同事务；幂等事件不重复，任务投递账本不参与活动裁剪。
- [x] 修复派生段落归属更新覆盖正文保存身份的问题，保留真实编辑者并随正文持久化。
- [x] 点击版本直接切换主文档正文，独立只读编辑器保留当前协同正文，切回后恢复实时编辑；移除高亮、比较、保存和侧栏预览控件。原版本接口保留兼容。
- [x] 浏览/编辑查询检查实时页面权限；跨知识库、私有页面与普通数据库角色均保持隔离。

## 保留口径

三类上限按每篇文档计算，命名版本和恢复备份同样计入十五个版本。浏览账户淘汰会删除该行的阅读/学习计数，统计基于保留记录。版本比较“当前版本”读取已持久化正文。运行时正文、现有任务投递去重及其他文档不受活动裁剪影响。
