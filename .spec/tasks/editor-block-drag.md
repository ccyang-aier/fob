# 文档块拖拽实施与验证

当前设计：[文档块拖拽](../../docs/editor-block-drag.md)。

## 实施

- [x] 在共享文档正文装配浮动六点手柄，统一支持本地、协作与文件夹正文。
- [x] 跟随鼠标的半透明渐隐虚影、源块淡化、蓝色边界插入线及边缘自动滚动。
- [x] 单事务移动、保留块 ID、列表同级排序、只读与销毁清理。
- [x] 集中登记官方 FA7 图标，无新增依赖。

- `bun test --isolate src/features/knowledge/editor/extensions/block-drag.test.ts`：8 项通过，覆盖双向整块移动、一次撤销/重做、整表与列表项、无效目标、协作期间源位置映射、只读清理、跨编辑器拒绝、Yjs 持久化与撤销。
- `keyboard-editing.test.ts` 的 24 项既有键盘行为与 `local-document-editor.instance.test.tsx` 的 3 项双面板同步回归通过。测试环境既有 KaTeX quirks-mode 和 React NodeView flushSync 提示保留；真实浏览器无新增应用错误或警告。
- 浏览器插件不可用，使用已有 Playwright CLI 和独立 Chrome 会话；测试数据位于此浏览器自己创建的本地知识库，未修改用户浏览器数据。
- 1440×1000 的真实浏览器通过：段落移至首位、列表项换序、块 ID 与存储内容对应、撤销/重做、刷新保留、Escape 取消、移出正文隐藏控件、26 段长正文拖至边缘自动滚动及清理。拖动前后的源 ID 不变，指示线在结束后消失。
- 浅色与深色查看六点手柄；390×844 窄屏下手柄完整落在视口内、正文无横向溢出。开发 CSS 热更新曾短暂丢失局部样式，刷新后恢复；视觉验收使用刷新后的页面。
- `pnpm typecheck`、`pnpm icons:verify`（包含在 lint）、`pnpm lint`、`pnpm architecture:verify`、`pnpm i18n:verify`、`pnpm build` 与 `git diff --check` 通过。构建产物在独立 `.next-build`，Web 与业务服务保持运行。
- 悬停、拖动中、完成后、深色与窄屏截图保存在本聊天仓库外的 Codex visualizations 目录，没有提交运行数据或截图。

## 虚影补充验证（2026-10-27）

- 原预览依赖视口外 DOM 的原生拖动影像；截图复核还发现 Tiptap 运行时 `.ProseMirror { position: relative }` 会覆盖单类预览定位。现用 `.preview.ProseMirror` 明确固定定位优先级，在正文之外显示跟随层，保留字体、宽度和抓取偏移，65% 不透明度并沿阅读方向渐隐。原生影像使用透明 canvas，避免叠加两份虚影。
- `block-drag.test.ts` 现为 9 项通过、83 个断言；新增实际 dragstart/dragover 路径覆盖预览完整文本、固定宽度、抓取偏移、60px 指针位移、inert/ARIA 隔离、导出与 JSON 不变，以及 dragend、Escape、只读和卸载后的清理。
- 1467×889 的真实 Chrome / Playwright 拖动确认虚影文本与源块一致、计算不透明度 0.65、渐隐蒙版生效、固定定位、屏幕范围及水平锚点正确、鼠标下移 60px 时虚影同步下移 60px。跟随层不增加正文布局高度；松手后块 ID 保留、虚影移除，撤销成功。最终截图实际包含独立的淡化源块与跟随虚影，浏览器控制台 0 错误、0 警告。
- `pnpm typecheck`、改动文件零警告 ESLint、`pnpm icons:verify`、`pnpm architecture:verify`、`pnpm build` 与差异格式检查通过。截图 `block-drag-ghost.png` 保存于本聊天仓库外 visualizations 目录。

## 空白行插入入口（2026-10-27）

- 空白段落、标题与仅空格/换行的书写行隐藏拖拽手柄，显示加号和本地化插入提示；空代码、图片和行内原子节点仍保留原有语义。
- 加号复用已有 Slash 菜单，使用零长度触发范围，打开与取消不写入 `/`；原有斜线输入、菜单键盘操作、插入及粘贴流程保留。
- `block-drag.test.ts` 与 `slash-paste.instance.test.ts` 共 31 项通过、248 个断言，覆盖空白判断、加号/手柄切换、提示不入文档、禁止空行拖动、打开/取消不改正文、空行转换成标题、元数据事务不关闭菜单，以及原有虚影、重排、只读、协作和粘贴回归。
- 1467×889 的真实 Chrome / Playwright 验证空文档及正文中的空行：无六点手柄，显示加号及“输入 '/' 来插入…”；打开/取消菜单不留下 `/`，通过加号成功插入主标题和次标题。空标题占位不被 H1/H2 级别标签覆盖，输入后恢复拖拽手柄。
- 有内容的块仍显示拖拽虚影，取消后清理；深色空行及 390×844 窄屏插入按钮检查通过。最终浏览器控制台 0 错误、0 警告。
- 类型检查、改动 TS/TSX 零警告 ESLint、图标、国际化、架构、生产构建及差异格式检查通过；保留现有基线保护并为实际修改更新了三个对应摘要。截图保存在聊天仓库外 visualizations 目录。
