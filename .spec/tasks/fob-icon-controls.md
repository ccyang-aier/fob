# Fob 控制图标修正

> 历史验证记录。图标来源与尺寸现已由 [FA7 迁移记录](fob-fa7-icons.md)及[图标系统](../../docs/ui/icon-system.md)取代；下文自绘 SVG/Phosphor 描述不再是当前实现要求。

当前造型规则见 [AI 前端规则](../../AI_FRONTEND_RULES.md#图标)与[全局界面组件](../../docs/architecture/fob-product-boundaries.md#全局界面组件)。

## 修正范围

- 实体型系统入口保留显式实心图标；共享 Context 改回 `regular`，避免把所有箭头、更多和指示符隐式变成填充变体。
- 主导航收纳恢复 `4fcf758` 的原始自绘圆角双栏 SVG、14px 尺寸与透明度。
- 前进/后退显式使用轻量 `regular`；对外打开箭头、更多、加减和关闭等控制恢复原有权重与留白。更多恢复独立三点。
- 本地与团队共用侧栏的分组指示恢复 `regular`，树节点指示恢复各自原有 `bold` 折线，切换器恢复轻量上下指示；不统一为实心三角。
- 恢复星标操作的未选中轮廓/已选中填充语义，不改变已有动作、数据和导航状态。

## 验证（2026-10-25）

- 主导航收纳 SVG 与 `4fcf758` 的原始 SVG 逐字比较一致；运行界面为 16×16 viewBox、14px 显示尺寸。
- 类型检查、受影响 TSX 的 ESLint 和架构边界检查通过。
- 导航所有者、收起入口与主题切换回归：8 通过、0 失败、40 断言。
- 浏览器检查轻量历史箭头、切换器和目录折叠指示、原收纳造型、签到卡片对外箭头；文件夹展开/收起和更多菜单可用。
- 更多图标恢复原 Phosphor `bold` 三点路径，包含三个独立圆形轮廓，不再使用填充变体的矩形底条。
- 验证页无框架错误覆盖层，控制台 0 错误、0 警告；截图仅保存在仓库外。本轮未新增移动端验证。
