# 成员管理与权限界面验收

日期：2026-11-07。当前设计见 `docs/ui/knowledge-base-members.md` 与 `docs/architecture/knowledge-permissions.md`。

## 实现范围

- 变更角色、创建邀请链接和完成按钮补齐统一系统图标；邀请与文件夹弹窗分别调整底栏上下留白。
- 单人及批量角色选项共享单行徽标菜单；所有者、管理员、编辑者、查看者、访客使用不同语义底色。
- 角色筛选宽 144px，复选框多选、组合取并集，选中保持展开；全部及清空筛选恢复完整目录。
- 根默认权限四个选项全部展示徽标，说明保留；新建文件夹缩小字段与按钮间距、增加底部留白。
- 成员侧栏、顶栏面板、直达页面、目录查询、角色与邀请管理、成员资源权限接口仅向当前库所有者开放。其他角色按实际文件夹与文档授权操作；本人自助退出和最后所有者保护保留。
- 管理员没有隐含的私有目录、文档授权、模板目的地、评论治理、资产上传或全库资产撤销能力。文档邀请会新增访客成员，也采用所有者门禁，接受时重验邀请者。
- 评论提及及人员字段使用 `page.people`，只返回当前文档可访问者的 userId、姓名及头像；过滤先于分页，兼容个人和历史分组授权，撤权／重建失败关闭。
