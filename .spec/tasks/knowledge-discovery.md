## 文件夹交互反馈修正（2026-10-26）

- 切换页签和搜索只更新列表；同一作用域内保留 FolderView、页头及页签 DOM。延迟响应回归验证 DOM 身份保持；知识库、文件夹或账号变化时拒绝沿用旧数据。服务端文件夹入口按 folder ID 恢复独立状态。
- 目录 API 只返回额外的图标字段，不带出概览和置顶 metadata。页头与服务端/本机侧栏共用值；选中图标实际 32px，侧栏 12px，再次选择或移除恢复默认。
- 收藏与侧栏复用黄色令牌；置顶使用明确的按下状态。文档页在后端分页之前优先置顶，也展示置顶子文档；其他排名不受影响，标题检索与 ACL 继续生效。本机列表采用同一分组规则。
- 新建改加号；导入增加上传图标及描边按钮容器。排序移至文档页签旁，更多菜单仅剩操作；默认权限复用自定义 PermissionSelect，支持选择、取消与 Escape。
- 前端 28 项专项通过（文件夹交互 7、查询保留/隔离 2、目录模型 14、图标/目录 5）；后端 25 项专项通过（发现接口 10、文件夹组织 HTTP 15）。一次性测试库均自动清理。新增分页用例通过真实权限重建生成多根文档 ACL，覆盖 40 + 5 分页、隐藏置顶与取消后恢复排序。
- 前端、服务端和共享契约类型检查通过；修改文件 ESLint、国际化和图标校验通过。最终 Next.js 生产静态导出和服务端构建通过。全库源码适配检查受其他正在进行的编辑器改动阻断；本轮适配 hash 已按明确文件清单核对，未替其他改动登记。
- 浏览器流：文件夹文档 → 热门/最近更新 → 页头与页签保留；排序选择 → 写入 → 恢复原排序；取消置顶 → 未置顶文档让位 → 恢复原置顶；独立验收文件夹选图标 → 页头和侧栏同步 → 再选同图标取消；权限菜单选择草稿值 → 取消，未改变实际权限。
- 使用内置 CUA 的独立验收页，未启用单独 Browser 插件或另装浏览器依赖。实际桌面 CSS 1347 × 758、手机 CSS 410 × 842，无整页水平溢出；手机置顶按钮保持可见。桌面刷新后名称、图标、排序和置顶仍保留；最终无框架错误遮罩，控制台 error/warn 为 0。
- 同时开发导致过 HMR 整页重载和一次浏览器控制超时，页面恢复后复核；此环境现象与延迟查询下的组件保留测试分别记录。结束时恢复桌面尺寸、展开侧栏，保留独立预览页。
