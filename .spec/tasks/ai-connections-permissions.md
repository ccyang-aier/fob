# AI 接入配置权限

日期：2026-11-10。当前设计见 [AI 接入设置](../../docs/ui/ai-connections.md)。

本页记录配置入口权限收紧时的验收。后续已将账户配置升级为知识库共享配置，数据作用域与迁移的当前结果见 [知识库共享模型配置](knowledge-base-ai-config.md)；本页的账户作用域描述仅为当时实施记录。

## 范围

- 所有者与管理员可配置当前服务端知识库中的个人 AI 连接；其他角色不挂载设置导航项和面板，搜索、窄屏导航与 `section=ai` 直达同样遵循权限。
- 工作区向煤球投影配置能力，权限变化参与上下文快照更新；普通成员的菜单和未配置提示不提供设置入口。
- 管理配置读取与全部配置操作要求经过刷新验证的管理角色；业务服务增加同样的权限检查。对话读取模型状态及正常聊天不受限制，持久化的账户 / 知识库作用域保持不变。

## 验证

- 设置导航、设置面板、连接表单、煤球与上下文：53 项通过、0 失败、259 断言。覆盖成员 / 查看者 / 访客、未知权限、未登录、本机、加载、搜索、直达和权限变化取消请求。
- 真实 PostgreSQL 与 HTTP 集成：24 项通过、0 失败、269 断言。覆盖三类非管理成员的九种配置端点全部返回 403，正常对话成功；所有者 / 管理员配置成功、跨知识库拒绝及管理员降级后的拒绝。
- 使用单独临时知识库进行真实界面验证，不修改现有知识库角色、连接或默认模型。普通成员的桌面 / 窄屏设置仅有外观、通用、关于；搜索 AI 无结果；直达 AI 显示外观页；煤球菜单仅有新对话、最近对话、煤球互动。
