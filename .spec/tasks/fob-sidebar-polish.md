# Fob 侧栏与文档工具批注调整

当前设计遵循 [AI 前端规则](../../AI_FRONTEND_RULES.md)及[图标系统](../../docs/ui/icon-system.md)。

## 完成范围

- 主导航收纳恢复用户指定的原双栏造型：两个圆角矩形的几何与 `d476397` 原版一致。它是集中目录中唯一保留的固定图形例外，图标检查脚本校验整个组件摘要，禁止在该例外中增加其它自绘图标。
- 文件夹、标签、最近等一级分组使用 FA7 实心三角，子级资源树保留轻量折线；上方菜单上移 4px。
- 底部统一为成员、模板、帮助、设置四行：30px 行高、2px 间距，图标左边线 16px、文字左边线 36px，与上方主导航一致；图标和文字中心线一致。收起时四个按钮均以侧栏中心线居中，设置始终是最后一行。
- 签到卡简化为咖啡图标、每日领取说明和领取按钮，去除常驻月度进度。卡片位于底部菜单组上方，仅在未签到时显示；请求期间保留卡片，服务端确认今日已签到后连同占位移除，刷新后保持隐藏，次日由已有北京时间跨日刷新机制恢复。月度记录继续在咖啡页面呈现。
- 系统与文档搜索统一为 FA7 `magnifying-glass`，在固定尺寸内加同色 16 SVG 单位的光学校正描边，保留官方填充路径；拆分视图统一为 FA7 `table-columns`，知识库页签使用闭合的 FA7 `book`；主题月亮按后续批注使用官方 FA7 Solid `moon`。
- 文档图标相对标题行垂直居中，标题编辑聚焦时无下划线；目录与星标加强激活底色调整为浅色 `#ebebeb`、深色白色 10%，共享 hover 调整为浅色 `#f1f1f1`、深色白色 6%。
- 侧栏分组在鼠标离开后清除悬停底条，普通鼠标焦点不再残留高亮，键盘焦点仍有反馈。缩放指示线统一为 1px，拖拽点击区保持原宽度。
- 文档目录每行使用单一按钮，父级整行折叠/展开，叶子项定位；保留稳定 heading ID、当前章节语义和 Enter/Space 操作。
