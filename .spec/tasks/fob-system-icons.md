## 完成范围

- `SystemIconScope` 提供 Phosphor `fill` 默认值，覆盖系统侧栏、顶栏及页签、设置和模板页面，并通过 React 上下文覆盖弹出菜单。
- 本地与团队知识库共用的分组、文件夹、标签、最近文档默认图标，成员、模板、设置、帮助以及全局搜索、主题、通知、咖啡均采用统一实心造型。
- 补查页签菜单、知识库切换器、账户菜单、设置项、签到页、模板与订阅入口；咖啡、模板和订阅界面由 Lucide 改用 Phosphor。
- 原有浅彩色主导航、用户文档图标、品牌、状态颜色及内容编辑语义保持各自定义。基础加减、关闭、勾选使用同系列无底框符号，避免填充变体额外带入方块。
- 更新受保护复制文件的实际适配记录，不通过 CSS 强制填充线性 SVG。
