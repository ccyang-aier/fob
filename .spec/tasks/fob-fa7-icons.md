# Fob FA7 图标迁移

当前规范见 [图标系统](../../docs/ui/icon-system.md)及 [AI 前端规则](../../AI_FRONTEND_RULES.md#图标)。本记录取代旧 Phosphor 实心默认值与自绘收纳图标方案。

## 文件夹重命名菜单（2026-10-26）

- 文件夹首页更多菜单的“重命名”补上集中目录的 FA7 Solid `PencilSimple` 图标，请求尺寸 14px，实际显示 12px；沿用现有菜单布局与权限条件。
- `pnpm icons:verify`、前端类型检查、修改文件 ESLint、架构完整性与差异格式检查通过。
- Browser 插件不可用，使用独立 Chrome/Playwright 在用户反馈的真实文件夹路径检查：深浅色均显示 12×12px 铅笔图标；点击可打开预填当前名称的重命名弹窗，取消正常，控制台无新增错误或警告。未提交名称修改，检查会话与截图不进入仓库。

## 尺寸收紧（2026-10-25，用户后续反馈）

- 所有数字尺寸图标在共享渲染层再缩小 2px：常规 16→14px、紧凑 14→12px、辅助 12→10px；明确的内容预览尺寸同样缩小 2px。
- Emoji 图标使用同一尺寸解析；按钮点击区域、图标选型、数据与操作保持原布局和语义。调用方保留原尺寸请求，避免逐处减小造成重复缩放。
- 图标与页面图标回归：6 项通过、0 失败、54 条断言。当前尺寸规则以本节和图标系统文档为准，下方保留首次迁移时的原始验证尺寸。
- 类型检查、受影响文件 ESLint、图标门槛通过；浏览器实测顶栏/更多 14px、树节点 12px、折叠 10px、标题图标 22px，按钮原有 28/30px 点击区保留，收起/展开正常，控制台 0 错误、0 警告。

## 完成范围

- 接入固定版本的官方 Font Awesome 7 Solid / React 组件，移除 Phosphor 依赖；所有 UI 图标统一从 `src/components/icons` 引用，按图标定义逐个导入，不引入整套运行时注册或远程图标服务。
- 资源实体、导航、设置、通知、咖啡、编辑器工具、数据库、身份、模板、评论与精灵控制均迁移；轻量箭头、更多、加减、关闭、勾选、收纳、折叠与状态轮廓由 Lucide 提供。
- 统一为常规 16px、紧凑 14px、辅助指示 12px；修正原 24px 的文档更多与 23px 的表格工具图标。多个候选中使用简单、圆润饱满的造型，例如咖啡选择 `mug-saucer`。
- 移除手绘 UI SVG：收纳、空状态、skills、滚动条箭头、帮助、复选勾、文件夹插图、星标反馈均使用官方图标；原滑块裁剪改为 CSS 圆角，不再维护 SVG 路径。
- 替换旧混合文件夹图标素材的运行时引用；34 个已有图标 ID、页面图标 ID、颜色、Emoji 和选中/未选中状态语义继续兼容。产品品牌和用户内容资源保留。
- 增加 `pnpm icons:verify`，并加入 lint；检查图标依赖、导入入口、手写 SVG、旧 weight 与混合素材引用。更新 AGENTS、前端规则、架构和当前图标规范；官方许可文本位于 `public/licenses/fontawesome.txt`。
