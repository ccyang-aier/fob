## 完成范围

- 接入固定版本的官方 Font Awesome 7 Solid / React 组件，移除 Phosphor 依赖；所有 UI 图标统一从 `src/components/icons` 引用，按图标定义逐个导入，不引入整套运行时注册或远程图标服务。
- 资源实体、导航、设置、通知、咖啡、编辑器工具、数据库、身份、模板、评论与精灵控制均迁移；轻量箭头、更多、加减、关闭、勾选、收纳、折叠与状态轮廓由 Lucide 提供。
- 统一为常规 16px、紧凑 14px、辅助指示 12px；修正原 24px 的文档更多与 23px 的表格工具图标。多个候选中使用简单、圆润饱满的造型，例如咖啡选择 `mug-saucer`。
- 移除手绘 UI SVG：收纳、空状态、skills、滚动条箭头、帮助、复选勾、文件夹插图、星标反馈均使用官方图标；原滑块裁剪改为 CSS 圆角，不再维护 SVG 路径。
- 替换旧混合文件夹图标素材的运行时引用；34 个已有图标 ID、页面图标 ID、颜色、Emoji 和选中/未选中状态语义继续兼容。产品品牌和用户内容资源保留。
- 增加 `pnpm icons:verify`，并加入 lint；检查图标依赖、导入入口、手写 SVG、旧 weight 与混合素材引用。更新 AGENTS、前端规则、架构和当前图标规范；官方许可文本位于 `public/licenses/fontawesome.txt`。
