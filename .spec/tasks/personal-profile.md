# 个人主页实施与验证

当前设计：[个人主页](../../docs/ui/personal-profile.md)。

2026-11-01 视觉返工：上一版视觉通过结论已撤回。根据用户反馈，将个人页恢复为系统紧凑尺度，热力图改为固定 3px 等距网格；用户进一步明确展示 12 个月并减少留白，现固定为全年 53 周。本轮独立记录新截图、间距和交互验证，下面历史验证不能替代本轮视觉复核。

2026-11-01 时间线精修：根据用户对活动区质感的进一步反馈，拆出独立 `ActivityEvent`，去除创建动态重复标题及日期；统一时间、节点和动作说明对齐，预览复用共享资源卡片，菜单靠近内容。实际验证卡片键盘打开文档／返回、菜单 Escape、焦点描边、深色材质及窄屏 258px 内容宽度；TypeScript、局部 ESLint、图标检查与生产构建通过。截图见工作区外的 `profile-timeline-*.png`，详情见根目录 `design-qa.md`。
