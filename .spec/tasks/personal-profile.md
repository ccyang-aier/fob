# 个人主页实施与验证

当前设计：[个人主页](../../docs/ui/personal-profile.md)。

- [x] 个人信息从弹窗改为工作台页面，支持页签、历史导航及设置返回。
- [x] 组件化页头、荣誉、活动日历、时间线、每日摘要和资源列表。
- [x] 真实账户和当前知识库数据；无虚构头像、活动、粉丝数或赠送结果。
- [x] 仅自己的资料与资源；真实 ACL、成员资格、分页与每日完整计数。
- [x] 页内名称编辑、搜索、排序、收藏及订阅；统一错误与 Toast。
- [x] 纯日历与本机作用域测试 3 项，以及 shell/页签回归 15 项通过（含个人主页目标交由知识导航所有者处理）。
- [x] 真实 PostgreSQL/HTTP 集成 4 项通过：主体／ACL过滤、参数与成员校验、先搜索再分页、过期 ACL 全面关闭。
- [x] 浏览器验证真实个人信息入口、日期筛选与每日计数、键盘日期选择、编辑校验与取消、搜索、收藏及取消收藏、关注筛选和未开放状态、文档／文件夹跳转、历史返回、设置关闭返回。
- [x] 桌面约 1487×1058、窄屏 391×844、默认约 643px 视口及深色主题视觉复核；窄屏页面无横向溢出，热力图独立滚动。
- [x] 前端／服务端／共享包类型、icons、lint、i18n、architecture 与生产 build 均通过。最终浏览器观察窗口无 error/warn，无框架错误遮罩。视觉比较和差异记录见根目录 `design-qa.md`。

数据库验证使用现有隔离测试库工厂，运行结束清理临时数据库，不重置开发库。浏览器仅在原有验收账户上执行可恢复的收藏操作，并还原该偏好；未修改原有昵称或正文。截图与浏览器证据仅保存在工作区外的可视化目录，不纳入提交。

成员关注、粉丝、头像上传、个人简介和咖啡赠送尚无服务能力，已明确呈现能力边界；不将这些记为已实现。
